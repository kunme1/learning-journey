函数也能作为参数

图片文字版（来源：image.png）：

普通参数可为数字、布尔、字符串及容器；函数参数传入处理逻辑。图中圆面积与成绩表为数据参数对照；核心调度代码：

def add(x, y):
    return x + y

def subtract(x, y):
    return x - y

def calc(x, y, oper):
    return oper(x, y)

result = calc(10, 20, add)
print(result)

原.py还定义multiply、divide，当前只运行calc(1,6,add)，实际7。传add本身，不是"add"，也不是提前调用add(...)的结果。补充（参考课程资料）：准确说需要可调用对象，函数是本课的例子；不局限于函数类型。divide的除零取决于输入，当前没触发；无需为四个运算教学例引入注册表或强行缩写。
