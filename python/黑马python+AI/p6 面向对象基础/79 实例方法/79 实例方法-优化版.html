实例方法与返回值

图片文字版（来源：image.png）：

定义实例方法时第一个参数用self，从实例调用时不用再手动传self。图中完整示例：

class Car:
    def __init__(self, brand, name, price):
        self.brand = brand
        self.name = name
        self.price = price

    def running(self):
        print(f"{self.brand} {self.name} 正在高速行驶中....")

    def total_cost(self, discount, rate):
        return self.price * discount + self.price * rate

c1 = Car("BMW", "X5", 500000)
total_cost = c1.total_cost(0.9, 0.1)
print(f"提车总价为: {total_price:.0f}")
c1.running()

图中接收变量total_cost与打印变量total_price不一致，原图照录；如果直接执行这一段会因total_price未定义报错。下面本地原代码已经用total1／total2对应接收和打印，不归为同一错误。

补充（参考课程资料）：c1.total_cost(0.9, 0.1) 可理解为 Car.total_cost(c1, 0.9, 0.1)；0.9／0.1是实参，discount／rate是形参，total1是赋值目标／变量名，方法计算结果叫返回值。对象调用时self自动绑定；ShoppingCart.run()直接从类调用却没给实例，通常缺少self；ShoppingCart().run()才创建实例后运行。

class car:
    def __init__(self, c_color, c_brand, c_name, c_price):
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        print("Car类型的对象初始化完毕,对象属性已经添加完毕")

    # 定义示例方法
    def running(self):
        print(f"{self.brand}{self.name} 正在高速行驶中....")

    def total_cost(self,discount, rate = 0.1):
        """
        计算提车的总费用, 包含了两个部分: 车的价格, 税费

        :param self: 
        :param discount: 折扣
        :param rate: 税率
        :return: 提车的总费用
        """
        total_cost = self.price * discount + self.price * rate
        return total_cost

# 测试
c1 = car("red", "BWM", "X5", 500000)

# 调用对象中的方法
c1.running()

total1 = c1.total_cost(0.9, 0.1)
print(f"提车的总费用为:, {total1: .0f}")

# 设置默认值之后可以不用设置参数
total2 = c1.total_cost(0.9)
print(f"提车的总费用为:, {total2: .0f}")

费用公式、执行与输出

先按价格×折扣，再加原价×税率，本课500000×0.9＋500000×0.1＝500000.0；第二次省略rate使用默认0.1，结果相同。这里税费公式是课程示例，未据现实政策延伸为购车财务建议。running只打印，正常结束返回None；total_cost先算再return，print才负责显示。

Python优化版：79 实例方法-优化版.py

可读性改进：直接return原两次乘法与相加表达式，car→Car。保留两个调用用于参数默认值比较。展示从 为:, {total1: .0f} 改成 为：{total1:.0f}，去掉多余逗号和正数前占位空格；数值不变，输出文本明确改变。没有代数提取公因子，因为浮点运算次序改变可能带来不同舍入。

# 原类名car合法；按类名大驼峰约定改为Car，并同步构造调用。
class Car:
    def __init__(self, c_color, c_brand, c_name, c_price):
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        print("Car类型的对象初始化完毕,对象属性已经添加完毕")

    # 定义实例方法
    def running(self):
        print(f"{self.brand}{self.name} 正在高速行驶中....")

    def total_cost(self,discount, rate = 0.1):
        """
        计算提车的总费用, 包含了两个部分: 车的价格, 税费

        :param self: 
        :param discount: 折扣
        :param rate: 税率
        :return: 提车的总费用
        """
        # 原先临时变量total_cost赋值后立即返回；直接return表达式，含义不变。
        # 保留两次乘法和相加顺序，不改成price*(discount+rate)，避免浮点舍入差异。
        return self.price * discount + self.price * rate

# 原演示在顶层；入口保护使导入不再创建对象或打印，直接执行保留演示。

昨日问答：格式化与文档字符串

print(c1.total_cost(0.9)) 可直接显示；需要复用、比较或调试时先保存成有意义的total。f"{total:.0f}" 显示0位小数但不改变原值；123.8显示124，int(123.8)得到123，二者不同。脚本只调用方法而不print不会自动显示返回值。print(... total: 1.float ...) 不是格式化语法；这属于历史截图问题，当前f-string已是合法写法。

三引号里的 :param:、:return: 是文档文字，不会让方法真的返回数据。模板是否生成由编辑器功能决定；昨日记录显示Pylance模板从未开启到已开启是先后状态，不能同时当当前事实。无显式return通常返回None，模板省返回说明不代表解释器异常。若希望无返回也固定出现return占位，记录里提供了autoDocstring自定义模板方案；本轮不安装扩展、不改配置，也不宣称模板界面已复测成功。

代码检查、英文命名与效率
