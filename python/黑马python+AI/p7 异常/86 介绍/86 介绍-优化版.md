两种处理：不处理则异常可中断当前执行；捕获匹配异常，执行预案后继续外层流程。通用形式try业务代码、except异常类型as变量、可选finally扫尾。图中代码：
```python
try:
    print("= = = = = = = = = = =")
    print(my_name)
    print("= = = = = = = = = = =")
except NameError as e:
    print("程序运行报错，错误信息是：", e)
finally:
    print("释放资源 ~")
```



**补充：**try异常点之后的语句跳过，执行第一个匹配的except，再继续整个try语句后面的流程；不是回到刚才那行自动重试。需要重输应由外层循环或调用方决定。

小结：捕获异常用于预案处理，finally可有可无。图中try为 `print("ABC".hello)`，依次捕获NameError、ZeroDivisionError、IndexError、Exception，最后finally打印扫尾。此表达式实际为AttributeError，前三类不匹配，进入最后Exception；图片的0不能作被除数仍需纠正。
```python
try:
    print("ABC".hello)
except NameError as e:
    print("名称不存在，请检查，具体信息:", e)
except ZeroDivisionError as e:
    print("0不能做被除数，请检查，具体信息:", e)
except IndexError as e:
    print("索引错误，请检查，具体信息:", e)
except Exception as e:
    print("其他错误，请检查，具体信息:", e)
finally:
    print("无论正常执行还是出现异常，都要释放资源 ~")
```



**补充／纠正：**finally通常在退出try前执行，即使异常未捕获也先扫尾再上报；不是断电／进程强制终止时也绝对执行的保证。单独print“资源释放”没有实际关闭资源。参照[Python异常与清理](https://docs.python.org/3.12/tutorial/errors.html#defining-clean-up-actions)。

```python
"""
```

```python
class student:

        self.name = name
        self.chinese = chinese
        self.math = math
        self.english = english

    def __str__(self):
        return f"姓名: {self.name} | 语文: {self.chinese} | 数学: {self.math} | 英语: {self.english} | 总分: {self. chinese + self.math + self.english}"

        if chinese is not None:
            self.chinese = chinese
        if math is not None:
            self.math = math
        if english is not None:
            self.english = english





# 教务管理系统类

    system_version = "1.0"
    system_name = "教务管理系统"

    def __init__(self):

    # 添加学生成绩

        name = input("请输入学生姓名: ")

        # 判断学生姓名是否存在, 如果存在,则添加失败(不能重复添加)

            if s.name == name:

            print("各科成绩必须在 0 - 100 之间 !")

                    print(f"修改后的成绩:{s}")
                    return

                else: 
                    print("各科成绩必须在 0 - 100 之间 !")
                    return

        print("未找到该学生,修改失败!")

    def del_student(self):

        for s in self.student_list:
            if s.name == name:
                self.student_list.remove(s)
                print("学生信息删除成功")
                return

        print("未找到该学生,删除失败!")
        
    # 查询指定学生成绩

        for s in self.student_list:
            if s.name == name:
                print(f"当前成绩:{s}")
                return
    
        print("未找到该学生!")

    def list_student(self):
        for s in self.student_list:
            print(s)

    def run(self):
        print(f"欢迎使用教务管理系统 {EduManagement.system_version}")

        while True:
            print()
            print("# # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # #")

            print()

            choice = input("请选择要执行的操作,输入 1-6: ")
            match choice:
                case "1":
                    self.add_student()
                case "2":
                    self.update_student()
                case "3":
                    self.del_student()
                case "4":
                    self.query_student()
                case "5":
                    self.list_student()
                case "6":
                    print("Bye ~")
```

```python
if __name__ == "__main__":
    edu_management = EduManagement()
    edu_management.run()
```
