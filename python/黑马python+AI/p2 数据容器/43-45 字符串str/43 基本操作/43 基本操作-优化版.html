可迭代性、字符串特点与索引

原笔记将可迭代性记为“可以通过循环一个一个遍历出来”，含义正确。字符串是字符的序列，顺序不等于按字母排序。

图片文字版（来源：image.png）：

字符串是字符的容器，可由单引号、双引号、三引号定义；不可变、有序、可迭代。Python示例的字符和索引：

字符 P y t h o n
正向索引 0 1 2 3 4 5
反向索引 -6 -5 -4 -3 -2 -1 
# 字符串 基本操作 ---> 不可变的（无法修改）,有序性，可迭代性
s = "Hello Python"

# 有序的
print(s[4])# 正向索引
print(s[-8])# 反向索引 

# s[4] = "X"
# print(s)
# 报错 'str' object does not support item assignment

# 可迭代性
for i in s:
    print(i)

执行过程：s是"Hello Python"，s[4]和s[-8]都为o；for依次取得每个字符（包括空格），不是自动取得索引。第8行修改项被注释，当前不会报错；若启用则TypeError。

补充（参考课程资料，P43）：不可变是不能原地替换字符串项，不是名称s不能重新赋值。切片返回结果，原s仍保持不变；这与C字符数组的可修改内容不能混为一谈。

序列与切片：省略边界和方向

图片文字版（来源：image-1.png）：

语法：序列对象[开始索引:结束索引:步长]；结束位置不包含，正负索引均可，步长正向／反向决定遍历方向。图中原说法：结束索引未指定默认为-1。示例以"Python"切片：s[0:5:1]为"Pytho"，s[0:5:2]为"Pto"。

纠正：省略终点不是写-1。"Python"[:]实际为"Python"，"Python"[:-1]是"Pytho"；负步长省略终点则允许跨过第一个字符。教材P43的“截到末尾”比图片的-1简写准确。

# 切片
print(s[0: 5: 1])
print(s[: 5: 1])
print(s[: 5: ])
print(s[: 5])

print(s[6: 12: 1])
print(s[6:: 1])

# 步长 ---> 正数：从前往后截取； 负数： 从后往前截取
print(s[0: 5: 2])
print(s[0: 5: -1])# 方向冲突，没有截取
print(s[5: 0: -1])

# 反转字符串
print(s[::-1])
原写法 本脚本实际结果 解释
s[0:5:1]、s[:5:1]、s[:5:]、s[:5] Hello 相同省略形式，保留作教学对照
s[6:12:1]、s[6::1] Python 从索引6到末尾
s[0:5:2] Hlo 索引0、2、4
s[0:5:-1] ''（空字符串） 起点0无法按负步长走到较大的终点5
s[5:0:-1] ' olle'（前导空格） 索引5为空格，取5、4、3、2、1，不含0
s[::-1] nohtyP olleH 反转整个字符串

补充：11月21日问答纠正链。sen[-1:-len(sen):]默认步长+1，不能向左走；即使末尾加-1，显式终点-len(sen)仍排除了第一个字符。完整反转用sen[::-1]，回文还要比较sen == sen[::-1]。不能因为算出反转串就认为已判定回文。
