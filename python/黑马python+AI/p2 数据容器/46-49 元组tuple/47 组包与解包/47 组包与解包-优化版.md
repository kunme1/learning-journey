## 组包与基础解包



![原课件 image.png](<image.png>)

**图片文字版（来源：image.png）：**

组包Packing把多个值合并到容器，解包Unpacking把容器拆成独立值分给变量。图中代码和星号分配示例：

```python
t1 = (5, 7, 9, 1)
t2 = 5, 7, 9, 1
a, b, c, d = t1
x, *y, z = t2       # x=5, y=[7,9], z=1
s, *o = t2          # s=5, o=[7,9,1]
*o, e = t2          # o=[5,7,9], e=1
```



**补充（参考课程资料，P47）：**元组组包关键在逗号，多数表达式场景可省括号；普通解包需数量一致。解包也适用于列表等可迭代对象，不只tuple。



```python
# # 组包与解包
# # 组包操作
# t1 = (5, 7, 9, 10, 2, 23, 12)
# t2 = 5, 7, 9, 10, 2, 23, 12

# print(t1)
# print(t2)

# # 解包操作
# # 基础解包(变量数量与容器的元素个数一致)
# a, b, c, d, e, f, g = t1
# print(a, b, c, d, e, f, g)
```

源t1有7项(5,7,9,10,2,23,12)，与图中4项不同；其组包和解包段都已注释。

![原课件 image-2.png](<image-2.png>)

**图片文字版（来源：image-2.png）：**

同一六变量解包报错ValueError: too many values to unpack (expected 6)。说明被取出的值多于6。



```python
# # *扩展解包（* 收集剩余的所有元素， 封装到列表list中）
# first, second, *other, last = t1
# print(first)
# print(second)
# print(other)
# print(last)

# *other, last2, last1 = t1
# print(other)
# print(last2)
# print(last1)
```

按源代码7项数据：first=5，second=7，other=[9,10,2,23]，last=12；第二种*other,last2,last1则得到other=[5,7,9,10,2]、last2=23、last1=12。

**补充（参考课程资料）：**星号接收结果始终为list，接不到中间项时也可为空表；同一层赋值目标最多一个带星目标，且非星号目标数量不能超过输入项数。独立边界例：

```python
first, *middle, last = (1, 2)
print(first, middle, last)  # 1 [] 2
```



## 案例：两个变量交换与三个值轮换



![原课件 image-3.png](<image-3.png>)

**图片文字版（来源：image-3.png）：**

①a=10、b=20，交换并输出；②a=100、b=200、c=300，把旧a、b、c分别赋给c、a、b，再输出。



```python
# 案例1
a = 10
b = 20

# 组包又解包
a, b = b, a

print(a)
print(b)

# 案例2
a = 100
b = 200
c = 300

c, a, b = a, b, c
print(a)
print(b)
print(c)
```

右侧先按旧值求出，再分配给左侧名称；不是先改a就丢掉其旧值。本源文件实际依次输出：

```text
20
10
200
300
100
```

第一题a=20、b=10；第二题a=200、b=300、c=100。`c,a,b=a,b,c`和`a,b,c=b,c,a`表达同一轮换方向，`a,b,c=c,a,b`则相反。

**纠正细节：**“先组包再解包”是理解求值次序的语言层面模型；不必据此断言解释器运行时一定分配一个临时tuple对象，更不凭一行就声称更快。C的逗号表达式与Python这里的组包赋值含义不同。
