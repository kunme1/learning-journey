### 按位置传递

![原图 image.png](<image.png>)

**图片文字版（来源：image.png）：**



```python
def reg_stu(name, age, gender, city):
    print(f"注册成功,姓名:{name}, 年龄:{age}, 性别:{gender}, 城市:{city}")
    return {"name": name, "age": age, "gender": gender, "city": city}

stu = reg_stu("张三", 18, "男", "北京")
print(stu)
```

实参按name/age/gender/city的顺序对应。

本课四个参数均必填；位置传参错序可能仍能运行而含义不对。当前本地三种调用相同学生数据，保留作为语法对照，未发现需要修改的问题。

**对应原始代码片段（保留注释状态）：**

```python
# ------------------------------------ 函数 - 传参方式 ------------------------------------

# 定义函数
def reg_stu(name, age, gender, city):
    print(f"注册成功，姓名：{name}，年龄：{age}，性别：{gender}，城市：{city}")
    return {"name": name, "age": age, "gender": gender, "city": city}


# 传参方式一：位置参数
stu = reg_stu("张三", 18, "男", "北京" )
print(stu)
```



### 按关键字或混合传递

![原图 image-1.png](<image-1.png>)

**图片文字版（来源：image-1.png）：**



```python
stu = reg_stu(name="张三", age=18, gender="男", city="北京")
stu2 = reg_stu(gender="男", name="王武", city="上海", age=22)
stu2 = reg_stu("赵四", 28, gender="男", city="上海")
```

关键字写形参名=值，彼此可调序；普通位置实参在前、关键字实参在后。

关键字参数不是Python保留字；关键字名称必须对应可接收它的形参。重复给同一形参既位置又关键字会TypeError。参数传递绑定对象，Python不会像C函数声明那样自动做静态类型检查。

**对应原始代码片段（保留注释状态）：**

```python
# 传参方式二：关键字参数
stu = reg_stu(name = "张三", age = 18, city = "北京", gender = "男" )
print(stu)

# 传参方式三：位置参数 + 关键字参数 ---> 位置参数在前,关键字参数在后
stu = reg_stu("张三", 18, city = "北京",gender =  "男" )
print(stu)
```



### 两种传参方式对比

**图片文字版（来源：image-2.png）：**



|方式|优点|取舍／场景|
|---|---|---|
|位置|简洁|参数少且顺序自然时方便|
|关键字|含义明显|参数多或易混时方便，代码更长|

# ------------------------------------ 函数 - 传参方式 ------------------------------------

def reg_stu(name, age, gender, city):
    print(f"注册成功，姓名：{name}，年龄：{age}，性别：{gender}，城市：{city}")
