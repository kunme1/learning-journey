### 追加、插入和按值删除


```python
# 列表定义
s = [56, 90, 88, 65, 90, 100, 209, 72, 145]
print(s)

# append(): 在尾部追加元素
s.append(188)
print(s)

# insert(): 在指定索引之前插入元素
s.insert(2, 80)
print(s)

# remove(): 移除列表中第一个匹配到的元素
s.remove(90)
print(s)
```

顺序为：初始9项，append188后10项；在索引2前插入80后11项；remove90只删遇到的第一个90，另一个保留。

### pop：删除并返回元素


```python
# pop(): 删除列表中指定索引位置的元素（如果未指定则默认最后一个）
# pop():会返回删掉的元素
e = s.pop(1)
print(s)
print(e)

e = s.pop()
print(s)
print(e)
```

前面的删除已改变索引。此时pop(1)取出80，而不是初始列表索引1的90；随后pop()取出末尾188。第21、25行都把返回值绑定到e，第二次覆盖第一次的值。

**纠正（参考资料与执行核对，P39）：**教材、复习笔记和P39逐字稿都说“同类型才能排序、数字与布尔混排不行”，这个概括不准确。实际`sorted([3,1.5,True])`为[True,1.5,3]；关键是元素能否按所用规则比较。教材“reverse后一定递减”的说法也只对先前已升序排列的状态成立：反转[2,9,1]得到[1,9,2]，并未排序。这些纠正保留在对应方法旁，不把资料当绝对答案。

### sort与reverse


```python
# sort(): 排序
s.sort()
print(s)

# reverse(): 反转列表元素
s.reverse()
print(s)
```

sort默认升序修改原列表，reverse反转当前顺序；本例先升序再反转，因此最终为降序：

```text
[209, 145, 100, 90, 88, 72, 65, 56]
```

【纠正】图片“类型一致才可排序”不够准确：元素需要能按所用规则比较，int和float可以混排；而int与str默认通常不能直接比较。相同类型对象也不一定定义排序关系。

【易错点】append、insert、remove、sort、reverse都是原地修改并返回None；pop返回被删除项。不要写 `s = s.sort()`，否则s变成None。remove找不到值会ValueError；pop空表或越界会IndexError，当前数据没有触发这些异常。

【可读性改进】s可改numbers，e改removed_item；`s.sort(); s.reverse()`在本例若只求降序可直接 `s.sort(reverse=True)`，但删除中间的print会少一条升序输出，且本课分别演示两种方法应保留。

**补充独立示例：**需要保留原列表时，可用sorted：

```python
numbers = [3, 1, 2]
ascending_numbers = sorted(numbers)
print(numbers)             # [3, 1, 2]
print(ascending_numbers)   # [1, 2, 3]
```

这会另建列表，不是对原程序的等价替换；是否保留原数据决定选哪一种。
