正负零分支与流程：先num>0，成立输出正数；否则判断num<0，成立输出负数；否则输出0。前一条件成立后不再判断后续条件。截图代码：

num = int(input("请输入数字："))
if num > 0:
    print(f"{num} 是 正数")
elif num < 0:
    print(f"{num} 是 负数")
else:
    print(f"{num} 是 0")

小结

文字版：

小结：多分支；elif可以多个，else可有可无且必须最后；按顺序判断，前面成立后不再检查后续。

补充：本课知识串联

if/elif/else 从上向下检查，进入首个成立分支后跳过后续分支。elif可有多个，else可省略但出现时必须最后。当前多账号示例每次只输出一次登录结果。
