## 列表定义、特点与索引



![课程原图 image.png](<image.png>)

**图片文字版（来源：image.png）：**

列表可以一次存放多个元素，定义用方括号；支持不同类型、有序、可重复、可修改。截图列表和索引关系：

```python
s = [54, 15, 75, 108, 23, 78, 75]
```



|正向索引|0|1|2|3|4|5|6|
|---|---|---|---|---|---|---|---|
|元素|54|15|75|108|23|78|75|
|反向索引|-7|-6|-5|-4|-3|-2|-1|


序列按位置排列并可通过索引访问；正向从0开始，反向从-1开始。

### 当前代码：定义与获取


```python
# 列表操作
# 定义
# 定义列表
s = [56, 90, 88, 65, 90, "A", "Hello", True]

print(type(s))  # 查看数据类型

# 访问列表元素
# 获取
print(s[0])   # 正向索引，从0开始，结果：56
print(s[-8])  # 反向索引，从-1开始，结果：56

print(s[2])   
```

实际列表有8项：s[0]和s[-8]都为56，s[2]为88；type(s)为list。“反向索引”是从末尾计数，不表示一定倒着遍历。

**补充：**合法单项索引范围为0到len(s)-1，或-len(s)到-1；越界读取会抛IndexError。C数组访问越界可能出现未定义行为，Python会明确检查并报错。

## 修改、删除、遍历与小结



![课程原图 image-1.png](<image-1.png>)

**图片文字版（来源：image-1.png）：**

小结：用[元素1,元素2,…]定义列表；可混合类型、重复、有序、可改。查看list1[0]；修改list1[0]="A"；删除del list1[3]；索引越界会报错。



```python
# 修改
s[5] = "ABC"
print(s)

# 注意：如果指定的索引超出范围，将会报错 list assignment index out of range
# s[10] = "DEF"
# print(s)

# 删除
del s[6]
print(s)

# 遍历
for item in s:
    print(item)
```

**执行解释：**第16行把索引5的"A"替换为"ABC"，长度仍为8；第24行删除索引6的"Hello"，后面的True向前移动，长度变成7；第28行逐项打印剩余元素。两次列表打印实际为：

```text
[56, 90, 88, 65, 90, 'ABC', 'Hello', True]
[56, 90, 88, 65, 90, 'ABC', True]
```

未发现需要修复的语法或逻辑错误。第19行注释中的“list assignment index out of range”专指越界赋值；越界读取通常是“list index out of range”，不应把两者当成完全相同的报错文字。注释掉的s[10]赋值不会在当前脚本运行。

【可读性改进】s可改为items以免误以为字符串；但本课list示例短，保留s也合理。第13行尾部空格可去掉，输出不变。列表访问、修改示例不需要额外函数封装。

**补充（参考课程资料，P37）：**第n个元素对应索引n-1；s[-1]取得末项，不需要预先数长度。直接查看列表名与for逐项输出用途不同。教材示例把越界赋值的报错简写成list index out of range，现按实际操作区分：读取通常为list index out of range，赋值为list assignment index out of range。
