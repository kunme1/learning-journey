# 改后：对四个课程集合各判断一次成员关系，True按1累加。

运算符与推导式

&交集、|并集、-差集。集合推导式：{表达式 for i in 列表}，带条件：{表达式 for i in 列表 if 条件}。

当前第4项先摊平成列表再逐人count，结果正确但重复扫描；优化版保留四份集合，以sum(student in course for course in courses)统计。新增生成器逐项给sum，bool按0/1相加；平均集合查询条件下由U×M次列表扫描降为4×U次成员检查，未计时，也不保证哈希最坏情形。
