### 三角形和数字行：注释代码的含义


```python
# 练习1
# a = int(input("请输入直角边的边长： "))

# for i in range(a):
#     for j in range (i + 1):
#         print ("*", end = " ")
#     print("")

# # 练习2
# num = int(input("请输入数字： "))

# for i in range (num):# 控制行
#     for j in range (1, i + 2):
#         print(j, end = " ")
#     print()
```

第一段外层i=0—a-1，每行i+1颗星；第二段外层i=0—num-1，内层1—i+1递增打印数字。两个段落目前不会执行。`print("")`与`print()`在这里都只输出换行，后者更简洁。

### 当前实际执行的棋盘


```python
# 练习3
# ▢■
# 8行 8列

for i in range(8):
    for j in range(8):
        if (i + j) % 2 == 0:
            print("■", end=" ")
        else:
            print("□", end=" ")
    print()
```

(i+j)为偶数输出黑格，奇数输出白格；向右或向下移动一步都会改变奇偶性，所以能交错。原脚本实际得到上面同样的8行棋盘，每行末尾另有空格。

【可读性改进】第27—29行i/j可改row/column，条件仍为 `(row + column) % 2 == 0`，结果不变。注释代码第11、12、18行的 `range (...)`／`print (...)` 去掉函数名后的空格；第13行 `print("")` → `print()`，不改变输出。两个三角形示例目的不同，不属于应删除的重复。

未发现当前棋盘逻辑错误。棋盘仅64格，没有值得专门提速的问题；用列表推导式合并输出会隐藏嵌套过程，本课无需强行替换。

### 命名检查


|原名|建议名|中文含义|文件位置|判断与原因|
|---|---|---|---|---|
|i、j|row、column（可选）|行、列|33 嵌套循环-案例.py 第27—29行|循环示例合法；新名明确坐标|
|a（注释）|side_length|直角边星号数量|33 嵌套循环-案例.py 第8行|a是数学示例名，新名说明语义|
|num（注释）|row_count|数字图形行数|33 嵌套循环-案例.py 第16行|不是任意数字，应明确行数|


补充：C与Python嵌套循环的执行层次相同，但Python用缩进而非大括号表示归属。
