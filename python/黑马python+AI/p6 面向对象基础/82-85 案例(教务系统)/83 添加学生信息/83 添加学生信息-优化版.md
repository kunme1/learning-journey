```python
    def add_student(self):
        name = input("请输入学生姓名: ")

        # 判断学生姓名是否存在, 如果存在,则添加失败(不能重复添加)
        for s in self.student_list:

```

输入name后，s是学生对象，`s.name == name`才比较姓名。当前break造成循环后继续添加；用return后，找到重复立即结束方法。范围条件已正确包含0、100，且三科用and保证全部满足。

**另一种有效思路（11月26日问答）：**for…else的else必须与for对齐，自然结束才执行；不是if的else。若只将return换回break而不移动后续添加，问题仍在。完整可运行修复和ValueError处理见[82 准备-优化版.py](<../82 准备/82 准备-优化版.py>)。
