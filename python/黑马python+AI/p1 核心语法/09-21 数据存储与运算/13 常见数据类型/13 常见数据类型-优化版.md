## 查看变量类型(变量里面数据的类型，变量是容器没有类型)

借助type()语句

![第13课原图 image-1.png](<image-1.png>)

**文字版：**

通过 type(要查看类型的数据) 得到数据类型。截图代码：
```python
print(type("Hello"))
print(type(10))
print(type(3.14))
num = 5.0
print(num)
print(type(num))
```

## 检查数据是否属于指定的类型，返回一个bool值

具体语法`isinstance(数据, 类型)`

### 对应案例代码（原稿所收录版本）

下面从原优化版收录的源码中提取实际执行语句，便于就近对照；注释练习与完整源码仍保留在文末。原稿的运行记录对应其标注版本，本次排版未重新执行程序。

```python
a = 10

a_type = type(a)

print("a =", a, "类型为：", a_type)

print(type("Hello"))

print(type(10))

print(type(3.14))

num = 5.0

print(num)

print(type(num))

print(type(True))

print(type(False))

print(type(None))

num = 5.0

print (num)

print (isinstance(num, int))

print (isinstance(num, float))

print (isinstance(num, bool))
```

小结：常见基础类型为 int、float、str、bool、NoneType；查看／检查类型用 type(...)、isinstance(...)。

### 补充：本课知识串联

认识 int、float、str、bool、NoneType；用 type(value) 查看实际类型，用 isinstance(value, type_name) 检查类型归属。变量名引用对象，类型属于对象；重新赋值可以让同名变量引用不同类型的对象。
