变量的作用范围

图片文字版（来源：image.png）：

num = 100
def circle_area(r):
    pi = 3.14
    area = pi * r * r
    return area
count = 0
c_area = circle_area(10)
print(c_area)

图中num/count/c_area为模块变量，r/pi/area为函数局部；局部名称不能直接在外部访问。

实际.py在函数内global num再令其为10000，调用后模块num也为10000；是本课有意演示。补充：只读取模块变量通常不需global，重新绑定才需；只要函数内赋值了同名局部，赋值前读取可能UnboundLocalError。图中“函数结束局部全销毁”是入门概括，返回的对象或闭包引用仍可能存活，作用域不是对象寿命。

对应原始代码片段（保留注释状态）：

# ------------------------------------ 函数 - 变量的作用域 ------------------------------------

# 全局变量
num = 100

# 定义函数
def circle_area(r):
    # 局部变量 : 只能在函数内部使用

    pi = 3.14
    area = pi * r * r

    # 局部变量num
    # num = 10000

    # global 关键字
    global num
    num = 10000
    print("num =", num)
    return area



# 调用函数
c_area = circle_area(10)
print(c_area)

print("num =", num)

调试开关例子

图片文字版（来源：image-2.png）：

debug_mode = False
def enable_debug_mode():
    global debug_mode
    debug_mode = True
    print("调试模式已开启")

def disable_debug_mode():
    global debug_mode
    debug_mode = False
    print("调试模式已关闭")
