五种导入及调用形式：

形式 示例 调用
整体导入 import random random.randint(10, 100)
模块别名 import random as rd rd.randint(10, 100)
指定成员 from random import randint, choice randint(10, 100)
成员别名 from random import randint as rint rint(10, 100)
通配导入 from random import * randint(10, 100)

第一行截图还展示 import random, os，可用但独立行通常更便于维护。

纠正：from random import randint 仍会加载random，只在当前作用域绑定randint；不是“完全不加载模块”。as 改变当前作用域使用的名字，不改源文件或模块真实名称。通配导入容易覆盖同名变量；演示语法可以保留，实际入口优先明确导入。

本地练习见module01独立笔记：当前rd绑定randint函数，不是random模块，调用应是 rd(1, 100)。

小结

图片文字版（来源：image-1.png）：

小结仍是五种形式：整体、模块别名、指定成员、成员别名、通配导入；导入通常放文件开头，但不是所有情况下必须在第一行。调用名字取决于import绑定了哪个名字。

补充（参考课程资料）：randint(a, b) 两端都包含；choice(sequence) 需要非空序列。from random * 少了import，是错误语法，但当前错误示例只在注释中，不阻止原练习运行。
