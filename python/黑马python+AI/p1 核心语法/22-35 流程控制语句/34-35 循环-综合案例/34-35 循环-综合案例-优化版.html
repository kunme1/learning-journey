break：结束当前所在的一层循环

图片文字版（来源：image-1.png）：

break只能出现在循环中，表示结束、跳出循环；通过break退出while时，循环else不执行。

补充：它退出最近一层循环，不自动退出所有嵌套循环。C和Python的break都与就近循环相关，但Python还需留意循环else。

continue：跳过本轮剩余语句

图片文字版（来源：image-2.png）：

continue只能出现在循环中，表示中断本次循环，直接进入下一次循环。

图片文字版（来源：image-3.png）：

同文件夹未在原.md引用的小结图：break表示结束、跳出；continue表示跳过本轮、进入下一轮。

补充：while里的continue会返回条件判断，for里的continue会继续取下一个元素。若把计数更新放在continue之后，它可能永远无法执行。

【错误修复】第71行 if count == 5 不区分第5次成功还是失败；第5次成功执行break后count仍为5，于是错误打印“您已达到操作上限”。已在内存提取注释段验证：前4次错误、第5次admin/666888时，会同时打印成功和上限。可将上限提示放进while的else，使break成功退出时跳过。

【需求明确】第53—55行空输入先continue，不执行第57行count+=1，因此空输入不消耗次数。若“五次机会”包含每次提交，应把计数放在所有输入校验之前，或使用for固定五轮；若只计算非空的认证失败，应保留不计次数但在笔记说明。

最小替换片段：将原注释段末尾的独立if改为循环else（与while对齐）；其他循环体不变：

count = 0

以上完整代码保留原先“空输入不消耗次数”的规则，只修复成功后仍提示上限的问题。

前瞻优化：完整可运行替代（字典与for/else）。下例定义每次提交都消耗一次机会，包括空输入；成功break后不提示上限，五次均未成功才走else。相比原版改变空输入计数规则，并统一“登录”文案。

accounts = {"admin": "666888", "root": "123123", "zhangsan": "123456"}
for attempt in range(1, 6):
    user_name = input("请输入用户名： ")
    password = input("请输入密码: ")
    if not user_name or not password:
        print("输入的用户名和密码不能为空！")
    elif accounts.get(user_name) == password:
        print("登录成功，进入B站首页~")
        break
    else:
        print("用户名或密码错误，请重新输入")
else:
    print("您已达到操作上限")

accounts.get查询对应密码；input一定返回字符串，因此未知用户返回的None不会等于输入密码。字典是减少重复维护，不凭3条账号就宣称性能提升。

补充：原注释版非整数字符串会抛ValueError。以下完整建议新增try/except，失败后continue重新读；这是新增错误处理，不表示原文件已修改。

import random
target_number = random.randint(1, 100)
while True:
    try:
        guess = int(input("请输入您猜测的数字："))
    except ValueError:
        print("请输入整数")
        continue
    if guess == target_number:
        print(f"猜对了，随机生成的数字是：{target_number}")
        break
    elif guess < target_number:
        print("猜小了")
    else:
        print("猜大了")

第98—105行求和已注释，筛选5的倍数累加，推导结果100500。第108—118行实际运行，遇到a加num_a并continue，跳过k判断；遇到k加num_k。实际输出：

该字符串中有 8 个 a, 6 个 k

可读性改进：第112—116行可用if/elif替代continue与第二个if，单字符不可能同时为a和k，因此两者计数相同：

count_a = 0
count_k = 0
text = "akiwksjakdiklowiqaamnvbamvaxnsjdsjkaaxkjd"
for character in text:
    if character == "a":
        count_a += 1
    elif character == "k":
        count_k += 1
print(f"该字符串中有 {count_a} 个 a, {count_k} 个 k")

前瞻补充：text.count("a")和text.count("k")可直接计数；这是两次扫描，原循环一次扫描但每个字符有分支，两者都为O(n)，未实测，不声称.count必然更快。保留continue版有教学价值。
