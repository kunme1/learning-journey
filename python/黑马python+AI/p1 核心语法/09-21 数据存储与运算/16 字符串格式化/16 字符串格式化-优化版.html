+号连接的缺点

  1. 拼接繁琐
  2. 破坏字符串完整性
  3. 类型转换

字符串格式化

第一种方式%s

文字版：

通过 % 占位符拼接字符串与变量；s 表示按字符串形式格式化。截图示例：

s1 = "涛哥"
print("大家好，我是%s，欢迎大家进入Python课程的学习" % s1)
s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆：%s，%s" % (s1, s2))

文字版：

前面 %s 的数量与后面提供的数据数量应一致；多个值按位置对应。

%s会自动转换为字符串

第二种方式

{}做占位符

文字版：

图中推荐 f-string：

name = "涛哥"
print(f"大家好，我是{name}，欢迎大家进入Python课程的学习")
s1 = "人生苦短"
s2 = "我用Python"
print(f"吉多·范罗苏姆：{s1}，{s2}")

小结

文字版：

小结：+ 拼接仅直接接受字符串；其他类型可 str(...)。旧式格式化单值为 "%s" % value，多值为 "%s,%s" % (value1, value2)；推荐 f"内容{变量/表达式}"。

补充：本课知识串联

%s 按位置格式化，多个占位符通常对应一个元组；f"内容{表达式}" 把表达式结果嵌入文本。%s 可把本例的整数格式化成字符串，不必手动 str(age)。

小练习与参考答案

预测 f"{3 + 5}" 的内容。答案："8"；花括号里可以是表达式。
