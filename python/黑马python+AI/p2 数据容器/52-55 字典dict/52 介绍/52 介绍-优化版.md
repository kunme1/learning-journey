## 字典

### 定义、取值与约束

![原图 image-2.png](<image-2.png>)

**图片文字版（来源：image-2.png）：**

键值对存储、key唯一、内容可修改。模板：

```python
dict1 = {"王林": 675, "李慕婉": 608, "许立国": 478}
dict2 = {}
dict3 = dict()
score = dict1["王林"]
```

图中另一个访问例写dict1["李思"]，需已有该键。value任意类型；图说key不能是list/set/dict。

**补充／纠正：**准确条件是键必须可哈希；不是任意元组都行，例如含列表的元组不可哈希。本批实际hash(([],))触发TypeError。普通list/set/dict不可作键。参考教材“必须不可变”的概括仅覆盖常见内置类型。

**对应原始代码片段（保留注释状态）：**

```python
# 字典
# 定义字典
dict1 = {"王林": 670, "李慕婉": 608, "徐立国": 508, "韩立": 688, "王林":700 }


print(dict1)
print(type(dict1))

dict2 = {0: 670, 1.5: 608, (1,2): 508, 3: 688}

print(dict2)

# 访问
print(dict1["李慕婉"]) # 获取
dict1["李慕婉"] = 688 # 修改
print(dict1["李慕婉"])
```


key值如果重复,后面的值会覆盖前面的值
