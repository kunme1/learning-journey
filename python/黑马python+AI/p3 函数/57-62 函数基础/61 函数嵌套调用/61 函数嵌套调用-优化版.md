### 嵌套调用与后进先出

![原图 image.png](<image.png>)

**图片文字版（来源：image.png）：**

在函数内调用另一个函数。函数调用遵循LIFO（Last In First Out，后进先出）。图中A先打印before→调用B，B先打印before→调用C；C打印c后返回B，B打印after后返回A，A打印after后返回顶层。原图三个函数与本地.py相同，代码见下方。

当前实际输出为a ... before、b ... before、c ...、b ... after、a ... after、函数调用完毕 ~。返回后接着调用点后续语句，不重新从函数开头执行。11月23日问答中的<module>表示文件顶层执行帧，不是异常，也不是额外自定义函数。课程调试快捷键是PyCharm环境，不能直接照搬成当前VS Code键位；本轮未操作编辑器。

**对应原始代码片段（保留注释状态）：**

```python
# 函数的嵌套调用
def function_a():
    print("a ... before")
    function_b()
    print("a ... after")


def function_b():
    print("b ... before")
    function_c()
    print("b ... after")


def function_c():
    print("c ...")


function_a()

print("函数调用完毕 ~")
```
