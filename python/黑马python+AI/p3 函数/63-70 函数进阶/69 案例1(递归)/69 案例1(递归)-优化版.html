递与归

图片文字版（来源：image-1.png）：

8!=8×7×…×1，7!、6!逐层减少，直到1!=1；递推f(n)=n×f(n-1)。流程：8调用7→6→…→1（递），1返回后逐层相乘得到2、6、24、120、720、5040、40320（归）。

原jc(10)实测3628800，当前正整数例正确；jc(0)或负数达不到n==1，最终RecursionError。优化版以factorial明确英文含义，支持0!并拒绝负数／非整数，保留递归教学；另给迭代替代避免调用栈增长，不声称未测试的提速。

# ------------------------------------ 案例 ------------------------------------

# 案例1：计算n的阶乘
# 递归调用(先层层递进, 再逐层回归): 指的是在函数中自己调用自己的情况 ---> 一定得有终结点
def jc(n):
    if n == 1:
        return 1
    else:
      return n * jc(n - 1)

result = jc (10)
print(result)

正整数例正确；0／负数递归无终点，优化版扩展0!并显式拒绝非法类型，保留递归与迭代对照。 配套文件：69 案例1(递归)-优化版.py。

"""来源：69 案例1(递归).py；配套：69 案例1(递归)-优化版.md。
整理日期：2026-11-23；原始练习不修改。
相关改写的原因和行为差异见就近中文说明。
"""

def factorial(n):
    """支持非负整数阶乘；保持递归教学，较大n仍受递归深度限制。"""
    # 原jc缩写不清，factorial是阶乘；原仅n==1导致0/负数无法终止。
    if type(n) is not int or n < 0:
        raise ValueError("n须为非负整数")
    if n <= 1:
        return 1
    # 原else前已有return，可直接写递归返回，逻辑更平直。
    return n * factorial(n - 1)


def factorial_iterative(n):
    """前瞻替代：循环避免递归调用栈；没有做运行速度基准。"""
    if type(n) is not int or n < 0:
        raise ValueError("n须为非负整数")
    result = 1
    for factor in range(2, n + 1):
        result *= factor
    return result


if __name__ == "__main__":
    # 只执行一种实现，避免为对照重复输出；两种实现分别在验证中比较。
    print(factorial(10))
