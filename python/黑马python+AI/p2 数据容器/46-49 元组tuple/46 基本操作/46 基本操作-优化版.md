## 从列表回顾到不可变序列



![原课件 image.png](<image.png>)

**图片文字版（来源：image.png）：**

回顾列表：元素可重复、有序、可以修改。如果记录的信息只能查询、不能修改，可考虑元组；元组创建后不可修改。

**补充（参考课程资料，P46）：**这里的不可变指元组各位置所引用的对象不能被替换、增删，不是“变量不能重新绑定”，也不是“嵌套对象保证全部只读”。比如`t = ([1],)`后`t[0].append(2)`会得到([1,2],)，元组的位置仍引用同一个列表。不能把教材“列表与元组唯一不同／所有里面数据不能改”的入门概括当作深层冻结保证。

## 元组定义、索引、切片与查询



![原课件 image-2.png](<image-2.png>)

**图片文字版（来源：image-2.png）：**

元组是不可变序列；可含不同类型，可重复，有序，支持索引和切片。原图示例：

```python
t1 = (5, 7, 9, 1, 2, 3, 10, 6, 4, 8, 12, 7, 5)
t2 = ()
t3 = tuple()
```

count统计元素出现次数；index查首次出现索引。



```python
# 元组基本操作 - tuple ---> 元组可以重复， 有序， 不可修改


# 定义
t1 = (80, 95, 78, 50, 76, 80, 85, 20)

print(t1)
print(type(t1))

# 索引访问
print(t1[0])
print(t1[-1])

# t1[0] = 100

# 序列类型可以切片
print(t1[0:5])

# count() 统计元素的个数
print(t1.count(80))

# index() 获取元素的索引(第一个元素的位置)
print(t1.index(80))
```

**执行过程：**源t1和图中t1是不同数据，源代码首尾分别80和20，前5项为(80,95,78,50,76)；80出现2次、首次索引0。count不是“返回元组总长度”，总长度应len(t1)。元素不存在时count为0，而index抛ValueError，区别于字符串find找不到时-1。

## 单元素逗号与小结



![原课件 image-4.png](<image-4.png>)

**图片文字版（来源：image-4.png）：**

小结：元组可重复、有序、不可修改；count统计次数，index找索引且缺失会报错；单元素元组末尾须有逗号，例如('A',)。



```python
# 注意点: 如果定义单个元素的元组，单个元素之后要加上逗号，比如(100, )
t2 = ()
print(t2)
print(type(t2))

t3 = (100, )
print(t3)
print(type(t3))
```

空元组()的类型仍是tuple；(100,)是单元素元组，(100)只是整数的括号。原有补充示例（当前源脚本已移除此调用）：tuple("ABC")迭代字符串得到('A','B','C')，不是只有一个元素"ABC"。

**纠正：**tuple是内置类型，tuple(...)是调用该类型的构造方式，不是“tuple语句”。教材把它简称函数可用于入门理解，但要区分实际对象类型；`()`和tuple()的选择在本小例主要是清晰，不报告未经测量的速度差。

实际完整输出：

```text
(80, 95, 78, 50, 76, 80, 85, 20)
<class 'tuple'>
80
20
(80, 95, 78, 50, 76)
2
0
()
<class 'tuple'>
(100,)
<class 'tuple'>
```
