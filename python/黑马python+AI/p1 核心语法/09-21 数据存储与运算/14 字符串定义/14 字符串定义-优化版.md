## 字符(基本单位)

![第14课原图 image-1.png](<image-1.png>)

**文字版：**

字符是文本世界的基本单位；一个字母、一个数字、一个标点符号、一个汉字等都可作为字符示例。

![第14课原图 image-2.png](<image-2.png>)

**文字版：**

图中双引号示例 s1 = "Hello"；单引号示例使用转义：
```python
s2 = 'It\'s very interesting'
```
三引号示例与 image.png 同一客户信函，内部换行与空格属于字符串内容。

字符串中想要使用引号要使用转义字符\，或者使用另一种引号

## 常见的转义字符

![第14课原图 image-3.png](<image-3.png>)

**文字版：**


|转义字符|名称|作用|
|---|---|---|
|`\'`|单引号|在内容中表示单引号|
|`\"`|双引号|在内容中表示双引号|
|`\n`|换行符|开始新的一行|
|`\t`|制表符|移动到后续制表位置；具体宽度依显示环境而定|

### 补充与纠正：本案例的代码检查

【注释纠正】第6行“官方推荐三双引号”需限定场景：文档字符串通常采用三双引号，普通多行字符串两种三引号都合法。第12行应理解为“三引号字符串内的 # 是字符内容”，并非真正注释被执行。单引号／双引号字符串也能用反斜杠连接源代码行，原注释“不能直接换行”指不能未经处理直接插入实际换行。

【可读性改进】例如 msg = 'It\'s very good' → msg = "It's very good" 可少用一次转义，输出不变；但本课保留两种形式有对比价值。C 的单引号常量与双引号字符串有不同含义，不能套用到 Python。

## 小结

![第14课原图 image-4.png](<image-4.png>)

**文字版：**

小结：单引号、双引号、三引号均可定义字符串；常见转义为单引号、双引号、换行和制表符；同一项目保持一致风格，三引号适合多行文本。

### 补充：本课知识串联

单引号和双引号定义的字符串类型相同；三引号允许内容包含实际换行。转义发生在字符串内部。Python 没有独立的 char 基础类型，单个普通字符也用 str 表示。
