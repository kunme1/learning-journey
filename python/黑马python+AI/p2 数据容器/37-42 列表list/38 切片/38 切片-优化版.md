## 切片：开始、结束与步长



![课程原图 image.png](<image.png>)

**图片文字版（来源：image.png）：**

切片截取数据的一部分；列表、字符串、元组均支持。课件示例：

```python
s = ["A", "C", "E", "B", "D", "E", "G"]
print(s[0:5:1])  # ["A", "C", "E", "B", "D"]
print(s[0:5:2])  # ["A", "E", "D"]
```

语法为序列[开始索引:结束索引:步长]，结束位置不包含；正负索引都可以。图中未指定开始默认0、结束默认长度、步长默认1。

**补充／纠正范围：**默认0与默认长度是正步长时的直观解释；负步长时省略边界有不同含义，`s[::-1]`可以倒序，不能机械替换成`s[0:len(s):-1]`。步长不能为0。

### 当前原代码与输出


```python
# -------------------------- 列表 list 切片 --------------------------

# 定义列表
s = ["A", "C", "H", "K", "L", "B", "D", "X", "C", "U"]

# 切片操作 [开始索引: 结束索引: 步长]
print(s[0:5:1])
print(type(s[0:5:1]))

print(s[:5:1])
print(s[:5:])
print(s[:5])

print(s[0:5:2])
print(s[0:-2:1])
```

源脚本使用10个字母，和图片中的7项示例不同，不要把图中结果套入原代码。实际输出逐行是：

```text
['A', 'C', 'H', 'K', 'L']
<class 'list'>
['A', 'C', 'H', 'K', 'L']
['A', 'C', 'H', 'K', 'L']
['A', 'C', 'H', 'K', 'L']
['A', 'H', 'L']
['A', 'C', 'H', 'K', 'L', 'B', 'D', 'X']
```

第7、10、11、12行取前五项，结果相同，属于省略语法对照；第8行再次切片并查看其类型为list；第14行每隔一项取索引0、2、4；第15行结束索引-2对应索引8，不包含8，因此得到前8项。

未发现当前切片结果错误。四种前缀切片写法是有意比较省略规则，不应都删掉。

【可读性改进】若实际业务需要前五项并多次使用，可先 `prefix = s[:5]`，再 `print(prefix)`、`print(type(prefix))`；这可替换第7—8行，输出不变，避免为查看类型再次构造相同切片。本例只有5项，收益很小，没有必要为它单独做性能设计。

**补充：**列表切片产生新列表，但通常是浅拷贝；内部若包含可变对象，仍共享这些对象。例如独立示例：

```python
original = [[1], [2]]
copy = original[:]
copy[0].append(9)
print(original)  # [[1, 9], [2]]
```

普通索引越界会报错，而普通切片边界超长通常会裁到实际范围，如s[:100]取得整个列表。

**补充（参考课程资料，P38）：**原笔记补上了“序列类型都支持切片”“有头无尾”；前文已覆盖范围规则。还需区分`items[:5]`是前五项形成的列表，`items[5]`是第六项。教材的一个步长样例正文混写了不同数据，按其图中`list("abchkl")[0:5:2]`实际为['a','c','k']，不是另一组a/e/d；不能据错例记结果。
