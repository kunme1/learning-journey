    print("这一年是闰年")
else:
    print("这一年是平年")

小结

文字版：

小结：else不需要条件，if条件不成立时执行；代码块都应保持一致缩进，建议4空格。

补充：本课知识串联

if/else 表达二选一：条件真走if，假走else；else不再写条件。闰年规则为能被400整除，或者能被4整除且不能被100整除。
