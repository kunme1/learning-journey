## 模式匹配 match-case

![第27课原图 image-1.png](<image-1.png>)

**文字版：**

match执行流程：先计算表达式，按顺序尝试case，成功则执行对应语句；都不匹配可进入case _。截图星期代码：
```python
day = input("请输入星期几(1-7)：")
match day:
    case "1":
        print("周一：工作会议日")
    case "2":
        print("周二：学习培训日")
    case "3":
        print("周三：项目开发日")
    case "4":
        print("周四：代码审查日")
    case "5":
        print("周五：总结规划日")
    case "6" | "7":
        print("周末：休息放松")
    case _:
        print("输入有误!!!")
```

## 小结

![第27课原图 image-3.png](<image-3.png>)

**文字版：**

小结：match表达式；case 值1；case 值2 if 条件（守卫）；case 值3 | 值4；case _。3.10新增；固定值分支可用match，范围与复杂组合条件通常直接用if。补充：match本身还支持解构等功能，不仅是固定值选择。

### 补充：本课知识串联

match/case 是Python 3.10引入的结构化模式匹配；本课用字面量模式按值分支。|组合候选模式，_作通配；case后可加if守卫。匹配首个成功分支后不会像C的switch那样继续落入下一分支，无需break。
