```python
# 字典常规操作
dict1 = {"王林": 670, "李慕婉": 608, "徐立国": 508, "韩立": 688}
print(dict1)

# 添加 - key值不存在就是添加
```

### 小结与遍历

![原图 image-2.png](<image-2.png>)

**图片文字版（来源：image-2.png）：**

新增与修改均d[key]=value；删除del或pop；查询[]、get、keys/values/items；支持for循环遍历键、值或键值对。

**补充（参考课程资料）：**d[key]找不到会KeyError，get默认返回None（也能指定默认值）；两者不能对全部边界称为“效果一样”。三个视图随字典内容动态变化，不是独立列表。遍历时增删字典项可能报RuntimeError。当前三种遍历是语法对照，应保留；for k in dict1可省keys()，对本普通字典键遍历结果相同，下面优化文件保留对照并就近说明。
