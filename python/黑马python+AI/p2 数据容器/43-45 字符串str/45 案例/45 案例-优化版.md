## 案例：按本课两条规则检查邮箱



![原课件 image.png](<image.png>)

**图片文字版（来源：image.png）：**

用户输入一个邮箱，检查包含一个@且至少一个点；满足输出“邮箱格式正确”，否则“邮箱格式错误”。



```python
# # # 法1

# # mail = input("请输入邮箱账号： ")
# # if mail.count("@") == 1 and mail.count(".") >= 1:
# #     print("邮箱格式正确")
# # else:
# #     print("邮箱格式错误")

# # 法2 in 运算符 ---> 判断子串是否存在字符串中，存在， 返回True； 否则， 返回Flase

# mail = input("请输入邮箱账号： ")
# if mail.count("@") == 1 and "." in mail:
#     print("邮箱格式正确")
# else:
#     print("邮箱格式错误")
```

这两套代码均已注释。第一套count("@")恰好1且count(".")至少1；第二套把点的计数改为`"." in mail`，在本课两条简化规则下等价。@不能直接改成`"@" in mail`，否则多个@也通过。第9行注释Flase确实拼错，应为False。



![原课件 image-1.png](<image-1.png>)

**图片文字版（来源：image-1.png）：**

如何判断指定子字符串是否出现：使用in运算符，返回bool值。

**补充（参考课程资料，P45）：**这是练习给定的简化检查，不是完整邮箱格式或可达性验证。`@.`也能通过两条条件，不能因此称作完整有效邮箱。正则可以表达更多语法规则，但正则匹配本身仍不能证明邮箱存在。完整保留本课规则的独立例：

```python
email = input("请输入邮箱账号： ")
if email.count("@") == 1 and "." in email:
    print("邮箱格式正确（仅符合本课两条规则）")
else:
    print("邮箱格式错误")
```

**图片文字版（来源：image-2.png）：**

练习1：输入字符串判断回文（两边对称）。图中示例为“黄山落叶松叶落山黄”“上海自来水来自海上”，没有逗号。练习2：输入10个字符串，反转后全部转为大写，记入列表并遍历输出。



```python
# # 练习1
```

回文判断本体是`sen == rsen`，反转只是准备步骤。当前采用sen[::-1]是正确写法；注释里另一条带显式终点的负步长写法仅在仔细处理端点时可用，优先省略两端。

**纠正（资料与原图交叉核对）：**二次教材及逐字稿把上述口头例子写入逗号，不能直接把逗号一起算进对称字符。实际核验：不含逗号的“黄山落叶松叶落山黄”为True，含逗号的“黄山落叶松，叶落山黄”为False。原图无逗号，保留原图题意；需要忽略标点则是新增的输入规范化规则，不能悄悄改变原题。

11月21日记录中的`sen[-1:-len(sen):]`失败原因已在第43课说明。空串按直接比较会是回文；若要求用户必须有内容，需额外拒绝空输入，属于行为变化。

## 练习2：先反转、再转大写、存表、逐项输出



```python
# 练习2
strings = []

for i in range(10):
    s = input("请输入字符串")
    # rs = s[::-1]
    # us = rs.upper()
    # strings.append(us)
    strings.append(s[::-1].upper())
# print(list) 错误 非遍历输出
for item in strings:
    print(item)
```

**当前执行过程：**10次input逐项读字符串；第37行链式调用先得到反转结果，再调用upper，append保存转换后的字符串。最后for逐项打印，不是打印整个列表。模拟输入以sddaw、ew、dds开头，实际前三条是：

```text
WADDS
WE
SDD
```

**共享问答的修正结果：**原先`us = s.upper`少括号，保存的是方法对象；`us = s.upper()`虽然调用，却仍在原串s上操作，没用到rs。当前第37行`s[::-1].upper()`已经修复两者，变量也已改为strings，不再遮蔽内置list。不能继续把旧错误列为当前缺陷。

**补充（参考课程资料）：**保留“输入—反转—大写—追加—输出”的数据流。对照展开如下，正常输入下和当前处理一致：

```python
strings = []
for index in range(10):
    text = input(f"请输入第{index + 1}个字符串：")
    reversed_text = text[::-1]
    upper_text = reversed_text.upper()
    strings.append(upper_text)
for text in strings:
    print(text)
```

这只增加输入编号提示、展示中间变量；输出的转换结果相同。二次教材称顺序反过来也一样，不能泛化到所有Unicode：字符ﬃ先反转再大写是FFI，先大写再反转为IFF（已运行验证）。因此按题目顺序写最清楚，不据ASCII样例推广所有文字。
