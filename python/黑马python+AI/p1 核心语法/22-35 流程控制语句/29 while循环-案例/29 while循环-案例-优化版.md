**文字版：**

案例：计算1—100之间所有偶数的累加和。思考1：num % 2 == 0判断偶数；思考2：用+=累加。

### 对应案例代码（原稿所收录版本）

下面从原优化版收录的源码中提取实际执行语句，便于就近对照；注释练习与完整源码仍保留在文末。原稿的运行记录对应其标注版本，本次排版未重新执行程序。

```python
i = 1

sumi = 0

while 1 <= i <= 100:
    if i % 2 == 0:
        sumi += i
    i += 1
else:
    print(sumi)
```

### 补充：本课知识串联

累加器先置0，每次把满足条件的值加进去；循环计数器每轮更新。1—100内偶数包含100，总和为2550。

### 补充：对应代码的执行过程与既有输出

i=1、sumi=0；while 1<=i<=100成立时，偶数加入sumi，无论奇偶都i+=1。到101退出，else打印2550。i+=1放在if外面是关键，若仅偶数时更新，第一次i=1就无法前进。

【可读性改进】第5行 while 1 <= i <= 100 → while i <= 100，在本例i从1只递增的前提下结果和次数不变；若未来允许i递减，则不能无条件删除下界。第9行else可去掉并在循环后print(even_total)，在当前没有break的程序中输出相同；保留else可用于练习其语法。

### 前瞻优化或补充示例

```python
even_total = 0
for number in range(2, 101, 2):
    even_total += number
print(even_total)
```
新增range起点、终点、步长；终点不包含101，所以能包含100。还可直接写 print(sum(range(2, 101, 2)))，sum负责累加，range不预先建完整列表；简洁但会隐藏累加器过程。公式法 print(50 * (2 + 100) // 2) 是本题算术等差数列的O(1)公式，适用于已知规则，不能代替一般筛选练习。C不能用Python式的连比表达区间。
