![第21课原图 image-1.png](<image-1.png>)

案例：①输入整数，判断是否在10—20之间；②输入整数，判断是否不在10—20之间。

### 对应案例代码（原稿所收录版本）

下面从原优化版收录的源码中提取实际执行语句，便于就近对照；注释练习与完整源码仍保留在文末。原稿的运行记录对应其标注版本，本次排版未重新执行程序。

```python
num = int(input("请输入一个整数:"))

print(f"{num} 不在 10-20 之间：" , num <10 or num > 20)

print(f"{num} 不在 10-20 之间：" , not(10 <=  num <= 20))
```

### 补充：本课知识串联

and 要求条件同时成立，or 只需一个成立，not 取反。可用10 <= num <= 20表达闭区间。Python 的 and／or 有短路行为，且一般返回某个操作数，并不保证总是返回 bool；本课两侧是比较式，所以结果是bool。
