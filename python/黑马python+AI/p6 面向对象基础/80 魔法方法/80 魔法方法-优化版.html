魔法方法

图片文字版（来源：image.png）：

魔法方法为Python约定的双下划线特殊方法，在相应操作时可自动调用，无需每次手动调用。图中清单：

方法 触发／作用
init 实例初始化
str str(obj)／print(obj)得到可读字符串
eq ==相等比较
lt / le < / <=
gt / ge > / >=

补充／纠正：这些名字是Python协议，不是任意造个dunder方法就会被自动调用；通常使用print、比较等语法触发，也允许显式调用方法用于调试，不应说绝对不能手动调用。

默认对象行为

图片文字版（来源：image-1.png）：

未自定义字符串／比较方法时：

class Car:
    def __init__(self, brand, name, price):
        self.brand = brand
        self.name = name
        self.price = price

    def running(self):
        print(f"{self.brand} {self.name} 正在高速行驶中....")

c1 = Car("BMW", "X5", 500000)
print(c1)
c2 = Car("BMW", "X5", 500000)
print(c2)
print(c1 == c2)  # 图示False
print(c1 < c2)   # 图示TypeError

两行对象输出形如 <__main__.Car object at 0x...>，不是属性明细；十六进制部分是本次运行信息，不能固定复用。默认未提供排序规则会报不支持比较的TypeError。

纠正：对没有重写比较的普通用户类，默认相等依据对象身份，不是先比较全部属性。不能把“==总是地址比较”推广到list、str或已定义__eq__的类；is才是身份运算符。默认表示常含地址式标记，也不是所有实现的固定地址格式。

自定义字符串与比较

图片文字版（来源：image-2.png）：

图中在同样的三属性Car类与running方法后添加：

def __str__(self):
    return f"{self.brand} {self.name} {self.price}"

def __eq__(self, other):
    return (self.price == other.price
            and self.brand == other.brand
            and self.name == other.name)

def __lt__(self, other):
    return self.price < other.price

这些方法缩进在Car类内。对两辆BMW/X5/500000，print各为“BMW X5 500000”，相等True，小于False。

补充（参考课程资料）：str__必须返回str，只有print而没return不行。只实现__lt，相同类型的 a > b 可尝试反向 b.__lt__(a)，不是自动对 a < b 求反；<=不由<和==自动合成。协议细节核对Python数据模型，本批用最小例验证。

class car:
    def __init__(self, c_color, c_brand, c_name, c_price):
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        print("Car类型的对象初始化完毕,对象属性已经添加完毕")

    # 定义示例方法
    def running(self):
        print(f"{self.brand}{self.name} 正在高速行驶中....")

    def total_cost(self,discount, rate = 0.1):
        """
        计算提车的总费用, 包含了两个部分: 车的价格, 税费

        :param self: 
        :param discount: 折扣
        :param rate: 税率
        :return: 提车的总费用
        """
        total_cost = self.price * discount + self.price * rate
        return total_cost

    def __str__(self):
        return f"{self.color} {self.brand} {self.name} {self.price}"

    def __eq__(self, other):
        return self.color == other.color and self.brand == other.brand and self.name == self.name and self.price == other.price

    def __lt__(self, other):
        return self.price < other.price

当前逻辑错误与建议

原相等条件含 self.name == self.name，漏掉other.name。原样例同型号未暴露，必须用“只改型号”的反例检查。最小修复只需把右侧改other.name；独立优化版同时为异类操作数返回NotImplemented，交给解释器回退。NotImplemented是特殊返回值，不是NotImplementedError异常。

Python优化版：80 魔法方法-优化版.py

错误修复：比较双方型号。前瞻健壮性：isinstance检查对方是否属于本课Car体系；否则返回NotImplemented。这让 car == "字符串" 通常最终为False，而 <无合适实现仍TypeError；不再直接因缺price属性抛AttributeError。保留按价格排序、按四属性相等的原教学规则，不增加<=等规则。

"""来源：80 魔法方法.py；配套：80 魔法方法-优化版.md。
复盘归属：2026-11-26；整理日期：2026-11-27（北京时间）。原始文件保留。
"""

# 原类名car合法；按类名大驼峰约定改为Car，并同步构造调用。
class Car:
    def __init__(self, c_color, c_brand, c_name, c_price):
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        print("Car类型的对象初始化完毕,对象属性已经添加完毕")

    # 定义实例方法
    def running(self):
        print(f"{self.brand}{self.name} 正在高速行驶中....")

    def total_cost(self,discount, rate = 0.1):
        """
        计算提车的总费用, 包含了两个部分: 车的价格, 税费

        :param self: 
        :param discount: 折扣
        :param rate: 税率
        :return: 提车的总费用
        """
        # 原先临时变量total_cost赋值后立即返回；直接return表达式，含义不变。
        # 保留两次乘法和相加顺序，不改成price*(discount+rate)，避免浮点舍入差异。
        return self.price * discount + self.price * rate

    def __str__(self):
        return f"{self.color} {self.brand} {self.name} {self.price}"

    def __eq__(self, other):
        # 错误修复：原self.name == self.name自比较，没比较另一辆车的型号。
        # 新知识：异类对象返回NotImplemented，让解释器尝试对方的比较协议。
        if not isinstance(other, Car):
            return NotImplemented
        return (self.color == other.color
                and self.brand == other.brand
                and self.name == other.name
                and self.price == other.price)

    def __lt__(self, other):
        # 原写法直接取other.price，对异类对象可能AttributeError。
        # 返回NotImplemented不是抛NotImplementedError；最终不支持的排序仍会TypeError。
        if not isinstance(other, Car):
            return NotImplemented
        return self.price < other.price
# 原演示在顶层；入口保护使导入不再创建对象或打印，直接执行保留演示。
if __name__ == "__main__":
    # 测试
    c1 = Car("白色", "BYD", "汉", 180000)
    print(c1)

    c2 = Car("白色", "BYD", "汉", 180000)
    print(c2)

    print( c1 == c2 )

    print( c1 > c2 )# 比大小会自动调用

小结

图片文字版（来源：image-3.png）：

小结：特殊方法外观__xxx__，相应操作可由解释器自动调用；__init__初始化、__str__字符串表示、__eq__相等、lt/le/gt/ge大小比较。

同价但不同型号可以 <和>都False、==也False；这是两种业务比较维度，不宜据此自动生成“完全有序”的判断。定义__eq__后此可变类默认不可哈希，不要立刻拿实例做set元素／dict键；本课不强加__hash__。

代码检查、英文命名与效率

当前默认样例两车型号相同，隐藏了__eq__里self.name==self.name的逻辑错误。构造仅型号不同、其他相同的两车，原版仍True，修正版False。异类对象比较返回NotImplemented是前瞻健壮性改进，不是把所有比较变False；不支持的排序仍TypeError。__lt__按价格比较，__eq__按全部字段比较，两种规则并非全序。
