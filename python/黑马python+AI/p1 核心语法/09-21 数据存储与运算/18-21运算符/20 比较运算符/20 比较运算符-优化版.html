!= 不等于 a != b
> 大于 a > b

< 小于 a < b
<= 小于等于 a <= b

补充：本课知识串联

比较运算符 ==、!=、>、>=、<、<= 在本课内置数字比较中返回 bool。= 是赋值，== 才是相等比较。判断余额够不够用 >=，需要同时另行判断金额是否合法。

补充与纠正：本案例的代码检查

【错误修复／注释示例】第14行 int(float(input(...))) 会先转换再截断，输入2.9会按2判断为偶数。若要求整数，应直接 int(input("请输入整数："))；原有 is_integer() 方案可保留作另一种输入契约。

【输入边界】当前余额比较本身正确；若要判断取款请求是否合法，需先排除非正金额。以下完整替换当前第26—29行，增加错误提示，改变了非法金额的输出；它仍未捕获非整数文本。Python 中 "100" == 100 为False，不能仅凭打印外观判断类型。
