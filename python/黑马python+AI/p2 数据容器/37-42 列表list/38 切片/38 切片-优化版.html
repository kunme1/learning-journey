切片：开始、结束与步长

图片文字版（来源：image.png）：

切片截取数据的一部分；列表、字符串、元组均支持。课件示例：

s = ["A", "C", "E", "B", "D", "E", "G"]
print(s[0:5:1])  # ["A", "C", "E", "B", "D"]
print(s[0:5:2])  # ["A", "E", "D"]

语法为序列[开始索引:结束索引:步长]，结束位置不包含；正负索引都可以。图中未指定开始默认0、结束默认长度、步长默认1。

补充／纠正范围：默认0与默认长度是正步长时的直观解释；负步长时省略边界有不同含义，s[::-1]可以倒序，不能机械替换成s[0:len(s):-1]。步长不能为0。

【可读性改进】若实际业务需要前五项并多次使用，可先 prefix = s[:5]，再 print(prefix)、print(type(prefix))；这可替换第7—8行，输出不变，避免为查看类型再次构造相同切片。本例只有5项，收益很小，没有必要为它单独做性能设计。

补充：列表切片产生新列表，但通常是浅拷贝；内部若包含可变对象，仍共享这些对象。例如独立示例：

original = [[1], [2]]
copy = original[:]
copy[0].append(9)
print(original)  # [[1, 9], [2]]

普通索引越界会报错，而普通切片边界超长通常会裁到实际范围，如s[:100]取得整个列表。
