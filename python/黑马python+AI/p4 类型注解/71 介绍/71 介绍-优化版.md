## 类型注解与容器

![原图 image.png](<image.png>)

**图片文字版（来源：image.png）：**

左侧未注解，右侧以 `变量名: 类型 = 值` 声明：`a: int = 695`、`score: float = 98.5`、`hobby: str = "Python"`、`flag: bool = True`、`pic: None = None`；`names: list[str] = ["A", "C", "E"]`；`phones: set[str]` 装手机号字符串；`options: dict[str, int] = {"count": 0, "total": 0}`；`goods: tuple[str, int, int] = ("手机", 5999, 1)`。图中的样本值与本地代码不完全相同，两者分别保留，不将手机号当数值相加。

**补充（参考课程资料）：**`tuple[str, int, int]` 固定三个位置；`dict[str, int]` 分别约定键、值；`list[str | int]` 允许每项为字符串或整数，不能写 `list[str or int]`。`|` 在注解里表示联合类型（Python3.10+），`or` 按真值短路并返回操作数；C的逻辑或通常写 `||`，不要把不同语境的 `|` 混用。


![原图 image-1.png](<image-1.png>)

**图片文字版（来源：image-1.png）：**

图片展示未写注解时，对整数695、浮点98.5、字符串"football"、布尔True、None，以及姓名列表、手机号集合、字典和元组进行类型推断；悬浮可见 `names` 为 `list[str]`。文字将其概括为“解释器自动推断”。此处可见的是编辑器／静态分析工具推断，不能据此认定运行时禁止重新绑定其他类型。

**纠正：**运行时对象有类型，变量绑定可以变化；静态工具根据赋值推断类型，是编辑器检查。`hobby = "Python"` 悬浮出现 `Literal["Python"]` 是字面量类型信息，不表示字符串变成常量。`hobby: str = "Python"` 与只允许单一字面量的 `Literal["Python"]` 约定不同。

def calc_order_cost(*args: tuple[str, float, int], coupon: int = 0, score:int = 0, express:float = 0.0) -> float:
    """
    根据传入的一批商品信息（商品名、价格、数量）、优惠（优惠券、积分抵扣）、运费信息计算订单的总金额

    :param args: 商品信息（商品名、价格、数量） ---> 如：（"鼠标", 188, 2）（"键盘", 388, 1）
    :param coupon: 优惠券
    :param score: 积分
    :param express: 运费
    :return: 订单的总金额
    """

    # 订单的总金额 = 商品总金额 - 优惠券 - 积分抵扣 + 运费

    # 1. 计算商品总金额
    total_price = [goods[1] * goods[2] for goods in args]
    total_cost = sum(total_price)

    # 2. 加载优惠券
    if total_cost >=5000 and total_cost >= coupon:
        total_cost -= coupon

    # 3. 加载积分抵扣
    if total_cost >= 5000 and score // 100 <= total_cost:
        total_cost -= score // 100 

    # 4. 添加运费
    total_cost += express

    return total_cost

# 测试
total = calc_order_cost(("鼠标", 188, 2), ("键盘", 388, 1), ("手机", 3999, 1), coupon=10, score=4000, express=9.9)
print(total)

上述代码先输出未注解列表，再输出三个订单金额。`names2.append(10023.0)` 不符合 `str | int`，但解释器不会因为注解阻止它；这是教学对照，保留并注明。订单参数 `*args: tuple[str, float, int]` 标的是**每一个位置实参**，例如一个商品三元组；函数内部的整个 `args` 则是多件商品组成的元组。把注解写成 `tuple[tuple[str, float, int], ...]` 会多包一层。`float` 约定可接受整数数值，不代表调用时自动把int转成float。

### 建议改写：[71 介绍-优化版.py](<71 介绍-优化版.py>)

## 小结与相关问答（11月23日记录）

**图片文字版（来源：image-2.png）：**

小结：类型注解给变量或函数指定预期数据类型，提高可读性、便于工具检查；格式 `变量名: 类型`。常见 `int`、`float`、`bool`、`str`、`None`、`list`、`set`、`tuple`、`dict`，联合类型可用 `str | int`。Python仍是动态类型语言，注解不是运行时强制转换。

Pylance是否报告参数不匹配取决于实际检查模式及诊断配置；本轮未改编辑器设置。诊断里 `object` 可能是append的形参名称，不能只凭这个词认定传入值已转为object。重复提示是否来自两个检查器，缺少诊断来源证据，不能断定。
