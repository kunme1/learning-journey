### 查找与计数


```python
# 字符串常用方法
s = "Hello-Python-Hello-World"

# find() 查找指定字符串第一次出现的索引的位置
index = s.find("-")
print(index)

# count() 统计子字符串在指定字符串中出现的次数
c = s.count("o")
print(c)
```

本串"Hello-Python-Hello-World"首次横杠索引5、小写o共4个。`find`缺失时返回-1，不能简单用`if s.find(...)`判断存在，因为索引0为假、-1反而为真；判断存在可用`sub in s`。

### 大小写转换、分割、清理和替换


```python
# upper() 转为大写
su = s.upper()
print(su)

# lower() 转为小写
sl = s.lower()
print(sl)

# split() 将字符串按照指定字符串切割 - 列表
slist = s.split("-")
print(slist)

# strip() 去除字符串两端的空格
ss = s.strip()
print(ss)

# repalce() 将字符串中指定字符串替换为新内容
sr = s.replace("-", "_")
print(sr)
```

**补充（参考课程资料，P44）：**这些方法不会原地改变s；upper/lower/strip/replace返回str，split返回list。第25行原串没有两端空白，所以结果看起来不变，不代表strip失效。`s.upper`只是取得方法，`s.upper()`才调用。

参数补充：默认strip移除两端空白（包括制表符／换行）；`strip("ab")`按字符集合反复去两端的a或b，不是删除一个完整前后缀；`split()`合并空白分隔，`split(" ")`按明确单空格切且可能保留空项，`split("")`会ValueError。这些是新增边界说明。

### 开头、结尾与不变性验证


```python
# startwith() / endswith() 判断字符串是否是以指定的字符串开头 / 结尾， 返回布尔值
print(s.startswith("Hello"))
print(s.endswith("Python"))

print("----------------")
print(s)
```

Hello开头为True，Python结尾为False（实际结尾是World）；最后重新print(s)确认原串未改变。实际整段输出：
