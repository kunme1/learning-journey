### 对应案例代码（原稿所收录版本）

下面从原优化版收录的源码中提取实际执行语句，便于就近对照；注释练习与完整源码仍保留在文末。原稿的运行记录对应其标注版本，本次排版未重新执行程序。

```python
dianliang = int(input("请输入电量："))

if dianliang <2880:
    print(f"电费是 {dianliang * 0.4883}")
elif 2880 <= dianliang <= 4800:
    print(f"电费是 {2880 * 0.4883 + (dianliang - 2880) * 0.5383}")
elif 4800 < dianliang:
    print(f"电费是 {2880 * 0.4883 + (4800 - 2880) * 0.5383 +(dianliang - 4800) * 0.7883}")
else:
    print("输入的电量不合理")
```

### 前瞻优化或补充示例

```python
electricity_kwh = int(input("请输入年度用电量（度）："))
if electricity_kwh < 0:
    print("输入的电量不合理")
elif electricity_kwh <= 2880:
    cost = electricity_kwh * 0.4883
    print(f"电费是 {cost:.2f} 元")
elif electricity_kwh <= 4800:
    cost = 2880 * 0.4883 + (electricity_kwh - 2880) * 0.5383
    print(f"电费是 {cost:.2f} 元")
else:
    cost = (2880 * 0.4883 + (4800 - 2880) * 0.5383
            + (electricity_kwh - 4800) * 0.7883)
    print(f"电费是 {cost:.2f} 元")
```
