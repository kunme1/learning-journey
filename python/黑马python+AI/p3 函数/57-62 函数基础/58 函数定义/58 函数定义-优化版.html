通式是def 函数名(参数列表):，缩进内为函数体，可有return；调用为函数名(实参)。图说先定义后调用，未调用函数体不运行。

# 注意：函数定义的时候并不会执行，只有在调用函数的时候，函数体的逻辑才会执行；函数必须先定义, 后调用

# 函数定义

def out_line():
    print("-------------------------------")
    print("-------------------------------")

# 函数调用
out_line()
out_line()

小结

小结

图片文字版（来源：image-1.png）：

函数先定义后调用；定义不会执行函数体，调用时才执行；缩进描述归属关系。

补充：执行def会创建并绑定函数对象；“不执行”是指函数体。本例调用前名称需已绑定；可以先写调用另一个函数的函数定义，只要实际调用发生时依赖函数已定义，P61就是例子。
