## 五种导入在原练习中的对应

对应P74，先区分注释比较与实际活动路径。

### 原始代码：[导入模块.py](<导入模块.py>)


```python
# 导入模块 ---> 调用方式: 模块名.功能名 / 别名.功能名
# import random
# import random as rd

# for i in range(100):
#     print(rd.randint(1, 100))

# 导入模块中的功能from ... import ... ---> 调用方式: 功能名 / 别名 ---> *:通配符
from random import randint as rd
# from random import randint
# from random *
print(rd(1, 100))
```

程序只执行最后启用的导入和一次print；原注释里的 `import random as rd` 绑定模块，而活动 `from random import randint as rd` 绑定函数。原代码有效，两种rd不是同一个概念。若取消 `from random *` 的注释，会因缺少import产生语法错误。

### 建议改写：[导入模块-优化版.py](<导入模块-优化版.py>)

**可读性改进：**直接用randint函数名，避免rd在“模块／函数”之间切换；没有添加随机种子或修改范围。代表性种子只在临时验证进程中设置，不写进交付脚本。


```python
"""来源：导入模块.py；配套：学习笔记-优化版.md。
整理日期：2026-11-24；原始文件保留。
"""

# 原活动语句：from random import randint as rd；print(rd(1, 100))。
# rd合法，但在本课另一注释中又代表random模块，容易混淆对象种类。
# 改为直接使用randint，名称就是“随机整数”；端点仍均包含，不改变随机范围。
from random import randint

print(randint(1, 100))
# 比较语法仍可写在原文件注释中；不把全部形式同时运行造成多次随机输出。
```

**补充（参考课程资料）：**导入成员仍会初始化其模块。`randint(1,100)` 包含1和100，不能将随机演示输出写成固定答案。本练习没有值得专门优化的性能问题。

## 代码、命名与效率检查

当前活动语句能运行；rd指函数，不能写rd.randint。输出为1—100的一个随机整数；代表性种子对照输出一致，并验证范围。注释中的多种写法用于教学保留；from random *仅为注释中的语法错误示例，不是当前运行错误。
