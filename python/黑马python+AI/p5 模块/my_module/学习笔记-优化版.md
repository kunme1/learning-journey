## 圆计算工具（P73披萨案例）

### 原始代码：[circle_fun.py](<circle_fun.py>)


```python
# 根据半径计算圆的面积
def circle_area(r):
    pi = 3.14
    return round(pi * r * r, 1)


# 根据半径计算圆的周长
def circle_len(r):
    pi = 3.14
    return round(2 * pi * r, 1)
```

circle_area接收半径，按3.14乘半径平方并round到1位；circle_len计算周长。本地main只用面积函数，保留周长函数作为复用示例；不把未被本入口调用等同于无用代码。半径单位由调用方约定，本案例为厘米，面积为平方厘米。

### 原始代码：[main.py](<main.py>)


```python



print("======= 计算披萨成本 ========")

# 披萨尺寸（半径，厘米）
s_radius = 10  # 小号披萨
m_radius = 15  # 中号披萨
l_radius = 20  # 大号披萨

# 计算面积
small_area = circle_area(s_radius)
medium_area = circle_area(m_radius)
large_area = circle_area(l_radius)

# 成本计算
small_cost = small_area * 0.05
medium_cost = medium_area * 0.05
large_cost = large_area * 0.05

print(f"小披萨面积：{small_area} cm²，成本：{small_cost:.1f} 元")
print(f"中披萨面积：{medium_area} cm²，成本：{medium_cost:.1f} 元")
print(f"大披萨面积：{large_area} cm²，成本：{large_cost:.1f} 元")
```

**错误修复：**第一处 `circle_area(s_radius)` 前没有任何导入；即使同目录有circle_fun.py，也不会自动把函数名注入main。干净进程实际先打印标题，再报NameError；不是函数公式错误。最小修复是在文件开头添加 `from circle_fun import circle_area`。

### 建议改写：[main-优化版.py](<main-优化版.py>)

**错误修复＋前瞻优化：**导入函数后，以列表和for解包统一三种尺寸，缓存带单位名称的成本单价，抽成main并入口保护。对合法原尺寸，公式、舍入、顺序与修复导入后的原程序一致；从“报错”变成完整打印，且被导入不再执行演示。没有加入负半径等新规则。


```python
"""来源：main.py；配套：学习笔记-优化版.md。
整理日期：2026-11-24；原始文件保留。
"""

# 原main.py调用circle_area却没有导入，第一处调用即NameError。
# 显式导入同目录原circle_fun.py的函数；不改3.14近似与round语义。
from circle_fun import circle_area

# 原来小、中、大各复制一段计算与输出；循环统一规则，新增尺寸时只需改数据。
# 新知识：列表装(label, radius)二元组，for解包；输出顺序仍是小、中、大。
# 单价0.05是元/平方厘米，名字明确单位；不是测得速度优化。
def main():
    print("======= 计算披萨成本 ========")
    cost_per_square_cm = 0.05
    for label, radius_cm in [("小", 10), ("中", 15), ("大", 20)]:
        area = circle_area(radius_cm)
        cost = area * cost_per_square_cm
        print(f"{label}披萨面积：{area} cm²，成本：{cost:.1f} 元")


# 原顶层输出移入函数；直接执行会运行，导入本入口不再打印。
if __name__ == "__main__":
    main()
```

3.14比math.pi精度低，但换常数会改变面积／成本；本次保留课程规则。循环主要减少维护重复，仍计算三个面积，不声称更快。与C的头文件声明不同，Python函数必须由导入或其他执行语句绑定到当前名字，文件相邻本身不完成绑定。
