原始代码：81 实例属性与类属性.py

# ---------------------------- 实例属性 与 类属性 ----------------------------

class Car:
    # 类属性(所有实例对象共享的)
    wheel = 4# 轮胎数量
    tax_rate = 0.1# 购置税税率


    def __init__(self, c_color, c_brand, c_name, c_price):
        # 实例属性
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        self.wheel = 2# 通过实例对象,在查找属性时,会先查找实例属性;不存在再查找类属性

    def running(self):
        print(f"{self.brand} {self.name} 正在高速行驶中....")

    def total_cost(self, discount, rate=0.1):
        total_cost = self.price * discount + rate * self.price
        return total_cost


# 测试
c1 = Car("白色", "BYD", "汉", 180000)
print(c1.wheel)

# 通过类名访问类属性
print(Car.wheel)

c2 = Car("黑色", "Tesla", "Model Y", 260000)
print(c2)

活动程序先建c1，实例有wheel=2，所以第一行2；类字段仍为4，第二行4。c2也初始化同名实例字段，最后print(c2)走默认表示，因为本文件没有__str__。示例输出形如 <__main__.Car object at 0x...>，其中十六进制值不固定。

Python优化版：81 实例属性与类属性-优化版.py

简洁性改进：只将立即返回的局部变量改为直接return，保留原两个乘法及相加顺序；类／实例wheel同名对照、两对象、默认对象表示都保留。入口保护只改变导入时是否执行演示。没有为改短强行删掉教学字段。

# ---------------------------- 实例属性 与 类属性 ----------------------------

class Car:
    # 类属性(所有实例对象共享的)
    wheel = 4# 轮胎数量
    tax_rate = 0.1# 购置税税率


    def __init__(self, c_color, c_brand, c_name, c_price):
        # 实例属性
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        self.wheel = 2# 通过实例对象,在查找属性时,会先查找实例属性;不存在再查找类属性

    def running(self):
        print(f"{self.brand} {self.name} 正在高速行驶中....")

    def total_cost(self, discount, rate=0.1):
        # 原先临时变量total_cost赋值后立即返回；直接return表达式，含义不变。
        # 保留两次乘法和相加顺序，不改成price*(discount+rate)，避免浮点舍入差异。
        return self.price * discount + rate * self.price


# 原演示在顶层；入口保护使导入不再创建对象或打印，直接执行保留演示。
if __name__ == "__main__":
    # 测试
    c1 = Car("白色", "BYD", "汉", 180000)
    print(c1.wheel)

    # 通过类名访问类属性
    print(Car.wheel)

    c2 = Car("黑色", "Tesla", "Model Y", 260000)
    print(c2)

易错点：rate=0.1在函数定义时已确定默认值，改变Car.tax_rate不改变该默认。若希望读实时配置，需要另定接口（例如rate=None时读取self.tax_rate）并解释行为变化，本批不把此业务变更悄悄混入等价版。

前瞻补充：不要将每个系统的 student_list=[] 写成类属性，多个系统会共享同一个可变列表；在__init__里 self.student_list=[] 每次新建才独立。与C里显式指针／结构体字段不同，Python赋值绑定可变对象时可能形成共享引用，不能只凭“两个变量名”推断有两份数据。

代码检查、英文命名与效率

self.wheel=2故意演示遮蔽类属性，不能误删；c1.wheel输出2、Car.wheel输出4。tax_rate类属性虽然存在，total_cost默认参数仍固定0.1，不会随改Car.tax_rate自动更新，这不是语法错误；本轮保留该演示契约。最后print(c2)为默认对象表示，不应假造固定地址。

原名 建议／保留 中文含义 位置 原因
wheel 保留；新接口可用wheel_count 轮胎数量 类属性／实例属性 原名像单个轮胎，数量名更明确；为保留同名遮蔽演示未改接口
tax_rate / rate 保留并说明未关联 税率配置／方法形参 类与total_cost 名字不同且默认值独立，不误称方法动态读取类属性
total_cost局部变量 直接return表达式 计算费用 方法末尾 无后续复用，表达更直接
