def load_session():
    sessions = []
    if os.path.exists("sessions"):
        for filename in os.listdir("sessions"):
            if filename.endswith(".json"):
                sessions.append(filename[:-5])
    return sorted(sessions, reverse=True)

__all__控制通配导出，不阻止 `from my import log_separator2` 这种明确导入；原本地代码的数据和符号与图不同，以下独立源文件按实物解释。

**纠正：**模块没有__all__时，通配导入通常取不以下划线开头的公开名字；不是无条件导入所有内部名字。大写PI是常量约定，Python仍允许重新绑定；与C的编译期const约束不要混同。

## 小结

![原图 image-2.png](<image-2.png>)

**图片文字版（来源：image-2.png）：**

小结：直接作为入口时 `__name__ == "__main__"`；被导入时 `__name__` 是模块名；`__all__` 控制 `import *` 的公开名字。图片将模块名简写成文件名（不含.py）。

**补充／纠正：**`python -m 包.模块` 也会让该入口的__name__为__main__；导入包内模块时名字可能为 `utils.my_fun`，不只裸文件名。__author__、__version__是常见作者自定义元数据，不是任何双下划线变量都由解释器自动赋值。
