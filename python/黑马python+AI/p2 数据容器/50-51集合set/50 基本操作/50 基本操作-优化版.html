为什么要用集合

去重的需求

图片文字版（来源：image.png）：

场景是批量存储唯一手机号。图中认为list/tuple能存重复项，所以不适合自动去重，set会去掉重复元素。

纠正（参考课程资料）：列表也能存这类数据，只是需要自行维护唯一性；不能把“不能自动去重”理解成“完全不能存”。电话号码宜存字符串，避免丢前导零。

集合

集合的定义

图片文字版（来源：image-1.png）：

集合无序、不可重复、可修改。定义例：

s1 = {"C", "D", "X", "T", "O", "U"}
s2 = set()

空集合不能写{}；不支持下标索引。

补充：set是内置类型，set()是构造调用，不是“set语句”。无序不等于每次随机打乱：同一未变集合多次打印可相同，但没有插入或排序顺序保证。11月22日的整数集合跨电脑顺序相同也不能证明集合有序；需要有序展示用sorted(s1)，得到列表且不改集合。

对应原始代码片段（保留注释状态）：

# 集合 set
# 定义
s1 = {5, 3, 2, 0, 9, 12, 43, 64, 22, 5, 0}

print(s1)
print(type(s1))

# 空集合不能直接定义
s2 = {}

print(s2)
print(type(s2))

# 定义空集合
s2 = set()

print(s2)
print(type(s2))

不可重复 ---> 自动去重

七种常见方法

图片文字版（来源：image-2.png）：

方法 图中含义 例子
add 加入元素 s1.add('t')
remove 删指定元素，缺失报错 s1.remove('t')
pop 图中写随机删并返回 e=s1.pop()
clear 清空 s1.clear()
difference 前者有后者无 s1.difference(s2)
union 并集 s1.union(s2)
intersection 交集 s1.intersection(s2)

纠正：pop是任意取出一个元素，不提供随机抽样保证；空集合pop、remove缺失均会KeyError。参考教材同样写“随机”，按Python 3.12官方定义纠正。方法返回新集合的三种集合运算不改变原集合。教材834—852行两份无交集数据却列出非空交集，不能照抄结果；本课以真实源s2/s3执行结果为准。

对应原始代码片段（保留注释状态）：

# 常见方法

# add(): 添加元素到集合
s1 = {100, 200, 300, 400, 5000, 600, 700, 800}
print(s1)

s1.add(1200)
print(s1)

# remove(): 移除集合中的指定元素(不存在将报错)
s1.remove(200)
print(s1)

# pop(): 随机删除集合中的元素并返回
e = s1.pop()
print(e)
print(s1)

# clear(): 清空集合
s1.clear()
print(s1)

s2 = {"A", "B", "C", "D", "E", "X", "Y"}
s3 = {"C", "E", "Y", "Z"}

# difference(): 求两个集合的差集(存在于第一个集合, 但不存在于第二个集合)
print(s2.difference(s3))
print(s3.difference(s2))

# union(): 求两个集合的并集
print(s2.union(s3))
print(s3.union(s2))

# intersection(): 求两个集合的交集
print(s2.intersection(s3))
print(s3.intersection(s2))

小结

小结

图片文字版（来源：image-3.png）：

无序、不可重复、可修改；定义{元素,...}或set()；add添加，remove/pop/clear删除，intersection/union/difference做交并差。
