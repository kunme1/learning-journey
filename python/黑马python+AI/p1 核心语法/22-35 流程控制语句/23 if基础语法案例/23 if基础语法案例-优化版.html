案例1

文字版：

需求：结合输入输出与if判断，模拟B站登录；示例正确账号18888888888、密码666888。仅为课件数据。

补充：本课知识串联

登录条件要求账号与密码同时匹配，用and连接两个相等比较。两种互斥结果适合if/else，而不是重复写正反两个if。账号和密码属于标识文本，通常按字符串精确比较。

文字版：

步骤：①提示输入账号和密码；②都正确则登录成功、进入首页；③有一个错误则登录失败并提示账号或密码错误。

文字版：

截图示例使用字符串与两个独立if：

ok_account = "18888888888"
ok_password = "666888"
account = input("请输入B站账号：")
password = input("请输入B站密码：")
if account == ok_account and password == ok_password:
    print("登录成功 ~")
    print("进入B站首页 ~")
if account != ok_account or password != ok_password:
    print("登录失败 !")
    print("用户名或密码错误 !")

补充：对应代码的执行过程与既有输出

原脚本第2—5行把正确账号、密码及输入都处理为整数。正确数字输入会成功，任一数值错误会失败；非数字文本在比较前就抛ValueError。前导零会被int去掉，使不同输入文本被当成相同数字；这与按文本匹配的需求不同。用户原笔记已说明自己使用if-else，这一选择是已有内容。

补充与纠正：本案例的代码检查

【错误修复／输入语义】第2—5行整数存储→字符串存储与直接input，保持课件数据不变。下方可完整替换当前脚本；原始正确账号仍成功，带额外前导零或非数字输入会按文本比较失败，而不再因int转换崩溃。
