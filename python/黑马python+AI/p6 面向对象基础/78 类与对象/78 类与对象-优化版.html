定义类并动态添加属性

图片文字版（来源：image.png）：

最简类与动态属性示例：

class Car:
    pass

c1 = Car()
c1.brand = "BMW"
c1.name = "X5"
c1.price = 500000
print(c1.__dict__)

通用形式为 class 类名: ...、对象名 = 类名()、对象名.属性名 = 属性值。类名推荐大驼峰，如UserInfo、UserAccount；__dict__以字典形式存实例属性。

补充（参考课程资料）：集中初始化便于读者看清对象的稳定结构。动态属性在Python中合法，也有用途；这里推荐init不是说解释器禁止后加属性。pass只是占位，不创建任何实例字段。

图片文字版（来源：image-1.png）：

窄幅终端截图可辨识默认对象表示，形如 <__main__.car object at 0x...>；尾部为十六进制身份／地址式信息。画面裁切且字号小，不抄写不可稳定确认的完整数串。不是业务属性值，也不是语法错误提示。

原笔记提示“类 对象 内存地址”。纠正：上述字符串是默认对象表示；在CPython中常包含地址信息，不是所有Python实现的统一地址保证，也不能假定每次启动必然不同。is比较身份，==可由类另行定义。

初始化属性与实例

图片文字版（来源：image-2.png）：

推荐在初始化方法里集中设置属性：

class Car:
    def __init__(self, c_brand, c_name, c_price):
        self.brand = c_brand
        self.name = c_name
        self.price = c_price

c1 = Car("BMW", "X5", 500000)
print(c1.__dict__)

self是第一个实例参数，表示当前实例；__init__在实例创建后执行初始化。图片把def在类外称函数、在类内称方法，作为入门识别法。

补充／纠正：self不是关键字，语法上可换名字，但规范约定用self；从对象调用绑定方法时自动传入实例，不是实例在执行时“没有第一个参数”。__init__负责初始化已创建实例，不应返回非None值。dict__显示此类普通实例当前直接存的字段，不能泛称所有对象必有__dict、所有可访问类属性都在其中。依据Python类与方法说明。

# self：是第一个参数，表示当前所创建出来的实例对象
class car:
    def __init__(self, c_color, c_brand, c_name, c_price):
        self.color = c_color
        self.brand = c_brand
        self.name = c_name
        self.price = c_price
        print("Car类型的对象初始化完毕,对象属性已经添加完毕")


# 创建对象
c1 = car("red", "BWM", "X5", 500000)
print(c1.__dict__)

c2 = car("白色", "1", "2", 300000)
print(c2.__dict__)

代码先保留动态属性的注释比较，活动部分定义四属性init。两次构造均打印初始化提示，然后分别打印red/BWM/X5/500000和白色/1/2/300000的字典；修改一个实例字段不应自动修改另一实例。
