### 补充：本课知识串联

if 条件: 后面是缩进代码块，条件为真时进入。冒号与缩进共同构成语法，通常每层4个空格。条件可以是任意可做真值判断的对象，并不要求事先得到bool对象。

## if条件判断

![第22课原图 image-1.png](<image-1.png>)

**文字版：**

if 执行流程：判断条件→成立则执行缩进块→继续后续语句；不成立则跳过缩进块。图中代码：
```python
score = 695
if score > 680:
    print("欢迎你，来清华读书")
    print("也恭喜你即将踏入精彩的大学生活")
```
图片要求条件结果为布尔值，属于入门简化；实际按真值测试。图中建议缩进4个空格。

### 对应案例代码（原稿所收录版本）

下面从原优化版收录的源码中提取实际执行语句，便于就近对照；注释练习与完整源码仍保留在文末。原稿的运行记录对应其标注版本，本次排版未重新执行程序。

score = 700
