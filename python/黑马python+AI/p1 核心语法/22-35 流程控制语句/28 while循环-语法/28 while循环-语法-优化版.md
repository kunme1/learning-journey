**文字版：**

while语法与流程：开始→判断条件→True执行循环体并回到判断，False结束；可选else处理正常结束。
```python
while 条件表达式:
    循环体语句1
    循环体语句2
else:
    正常结束时执行的操作
```
这是语法模板，占位文字需换成实际Python表达式。

## 例子

![第28课原图 image-1.png](<image-1.png>)

**文字版：**

示例：打印10遍口号。
```python
i = 0
while i < 10:
    print("人生苦短，我用Python~")
    i += 1
else:
    print("循环正常结束,执行完毕")
```
循环只在条件保持真时继续，条件永远为真会无限执行。

## 小结

![第28课原图 image-2.png](<image-2.png>)

**文字版：**

小结：while条件表达式后缩进循环体，else可选；用缩进表达归属；规划终止条件避免死循环。图中把条件表述为布尔结果，完整规则是按对象真值判断。

### 补充：本课知识串联

while在每轮前判断条件，为真执行循环体，再返回条件。循环体应使终止条件最终成立。else在循环正常结束且未通过break离开时执行，即使一开始就不进入循环也可能执行。
