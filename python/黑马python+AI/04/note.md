##3 多行代码放在.py文件里面
hello.py
### 方法一,手动切换目录
执行命令行：
```cmd
cd 文件所在目录
python hello.py
```
### 方法二
在hello.py所在资源管理器地址栏输入cmd(会直接进入当前目录)
然后运行
```cmd
python hello.py
```
