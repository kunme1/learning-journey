获取键盘的数据，并且输出到控制台

'input'获取 'print'打印

输入

文字版：

input 获取键盘数据，print 输出控制台：

name = input("请输入您的姓名：")
print(f"欢迎您，{name}")
age = input("请输入您的年龄：")
print(f"您今年 {age} 岁")

图中演示输入“涛哥”和18，并打印欢迎语及年龄。

文字版：

注意：无论键盘输入看起来像什么类型，input 成功返回的内容总是字符串。

文字版：

ATM 案例：初始余额10000元；依次输入密码、输入取款金额、计算余额并输出。原图为步骤要求，未给出密码校验或余额不足处理细则。

小结

文字版：

小结：s = input(提示信息)；常见转换为 int(...)、str(...)、float(...)、bool(...)。

补充：本课知识串联

input(prompt) 提示并读取一行文本，成功返回 str；print(...) 输出到控制台。做数值运算前先转换类型；int("1.5") 会失败，float("1.5") 才能读取这一小数。

补充与纠正：本案例的代码检查

【输入边界】第22行 int(num1) + int(num2) 在整数输入下正确。当前提示是“数字”，但1.5会触发 ValueError：若目标是整数练习，将提示改为“整数”；若目标包括小数，可以改为 float 输入，两者会改变可接受输入和部分输出格式。

【注释案例纠正】第12行打印密码不等于校验密码；可直接删除回显，只保留演示输入的说明，删除会改变控制台输出但不会添加校验功能。bool("False") 是 True，字符串只要非空通常就是真值。C 的 scanf 可按指定类型写入，Python input 不会自动推断数值类型。

前瞻优化或补充示例

【进阶建议／前瞻】新增 try/except/else 捕获整数转换失败；成功读取后才计算。失败时给出提示，区别于原脚本直接报错；本例不会反复重试。完整独立代码：

try:
    first_number = int(input("请输入第一个整数："))
    second_number = int(input("请输入第二个整数："))
except ValueError:
    print("请输入有效整数")
else:
    print(f"两个数字之和为：{first_number + second_number}")
