**文字版：**

for与while对比：while关注条件，for按可迭代对象逐个获取元素。流程为开始→是否还有元素→有则取出处理并继续，没有则结束。截图示例：
```python
msg = "Hello-Python"
for i in msg:
    print(i)
else:
    print("循环结束")
```

### 补充与纠正：本案例的代码检查

【可读性改进】第20行 range(0, 10) → range(10)，起点默认0，结果与顺序不变；如果要输出1—10应改range(1,11)，那会改变输出，不是等价简化。循环变量接收的是元素，不自动表示下标。

Python for不像C的for(初始化;条件;更新)，不需手动i++。range按需表示整数序列，不应为遍历先list(range(...))，额外建列表会增加内存。当前固定10次输出，无值得专门优化的性能问题。

## 小结

![第30课原图 image-1.png](<image-1.png>)

**文字版：**

小结：for 元素 in 待处理数据: 后写缩进循环体，else可选；while适合条件控制，for适合遍历／已知次数。图中else“不满足循环条件”应精确理解为迭代耗尽且未break。

### 补充：本课知识串联

for从可迭代对象中依次取元素处理；range(start,stop)包含start、不包含stop，range(10)等价于range(0,10)。循环else在遍历耗尽且没有break退出时执行。
