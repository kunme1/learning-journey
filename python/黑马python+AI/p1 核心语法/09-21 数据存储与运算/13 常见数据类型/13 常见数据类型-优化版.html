借助type()语句

文字版：

通过 type(要查看类型的数据) 得到数据类型。截图代码：

print(type("Hello"))
print(type(10))
print(type(3.14))
num = 5.0
print(num)
print(type(num))

小结

文字版：

小结：常见基础类型为 int、float、str、bool、NoneType；查看／检查类型用 type(...)、isinstance(...)。

补充：本课知识串联

认识 int、float、str、bool、NoneType；用 type(value) 查看实际类型，用 isinstance(value, type_name) 检查类型归属。变量名引用对象，类型属于对象；重新赋值可以让同名变量引用不同类型的对象。

小练习与参考答案

推导 isinstance(True, int)、type(True) is int 的结果。答案：True、False。
