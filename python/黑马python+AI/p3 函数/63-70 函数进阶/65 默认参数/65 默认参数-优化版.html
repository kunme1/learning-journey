缺省参数

图片文字版（来源：image.png）：

定义时给默认值，调用时可省。截图：

def reg_stu(name, age, gender, city="北京"):
    print(f"注册成功,姓名:{name}, 年龄:{age}, 性别:{gender}, 城市:{city}")
    return {"name": name, "age": age, "gender": gender, "city": city}

stu = reg_stu("张三", 18, "男")
print(stu)
stu = reg_stu("赵四", 22, "男", "深圳")
print(stu)

图中提示默认参数放非默认参数后；传值则本次取传入值。

纠正：调用时传city="上海"不会永久修改函数默认的北京；只是本次绑定。原.py有gender和city两个默认值：王林用男/北京，李慕婉覆盖女，韩立用city="上海"跳过gender。当前写法清楚，未发现需要改写的问题。补充默认对象在def执行时求值，可变默认参数会跨调用共享；本例用字符串没有此问题。默认参数后不能有普通必填位置参数；后续*后的仅限关键字必填参数是另一种合法情况，不把入门表述当全局禁令。

# ------------------------------------ 函数 - 默认参数 ------------------------------------

# 定义函数
def reg_stu(name, age, gender = "男", city = "北京"):
    print(f"注册成功，姓名：{name}，年龄：{age}，性别：{gender}，城市：{city}")
    return {"name": name, "age": age, "gender": gender, "city": city}

# 调用函数
stu = reg_stu("王林", 20)
print(stu)

stu = reg_stu("李慕婉", 18, gender = "女")
print(stu)

stu = reg_stu("韩立", 22, city = "上海")
print(stu)
