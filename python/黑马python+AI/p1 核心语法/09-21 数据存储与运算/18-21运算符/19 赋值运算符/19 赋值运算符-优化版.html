运算符 含义 本课整数对照
= 赋值 num = 1 + 2
+= 加后赋值 num += 2 ↔ num = num + 2
-= 减后赋值 num -= 2 ↔ num = num - 2
*= 乘后赋值 num *= 2 ↔ num = num * 2
/= 除后赋值 num /= 2 ↔ num = num / 2
%= 取模后赋值 num %= 2 ↔ num = num % 2
//= 整除后赋值 num //= 2 ↔ num = num // 2
**= 幂后赋值 num **= 2 ↔ num = num ** 2

补充：本课知识串联

赋值先计算右侧再绑定左侧；复合赋值把一次运算与回写合在一起。对本课整数可把 num += x 理解为 num = num + x，不能把这种等价无条件推广到所有可变对象。
