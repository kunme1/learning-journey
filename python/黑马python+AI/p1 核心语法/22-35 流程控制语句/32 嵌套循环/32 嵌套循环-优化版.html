嵌套循环的执行次序

图片文字版（来源：image.png）：

图中外层for遍历数据集1，外层循环体内还有内层for遍历数据集2。结构转写：

for outer_item in outer_items:
    # 外层的其他操作
    for inner_item in inner_items:
        # 处理当前这一对元素
        pass

补充：外层每取一个元素，内层都完整运行一次。矩形的行数由外层控制，每行的列数由内层控制。

案例：打印长方形

图片文字版（来源：image-1.png）：

打印长度为m、宽度为n的长方形。图中示意是4行、每行9个星号，星号之间留空格。

# 案例
m = int(input("请输入长度："))
n = int(input("请输入宽度："))

# print自带换行，不符合预期
# for j in range(0, n):
#     for i in range(0,m):
#         print("* ")
#     print("\n")

for j in range(n):# 控制行
    for i in range(m):# 控制列
        print("* ",end = "")
    print()

解释：m是每行列数，n是行数；第11行外层重复n次，第12行每行重复m次。第13行结束符为空字符串使星号留在当前行，第14行在内层完成后换行。注释版的普通print会每颗星换行，print("\n")还会叠加自带换行。

模拟输入m=3、n=2，实际图形部分输出（每行末尾有一个空格）：

* * * 
* * *

图片文字版（来源：image-2.png）：

截图对比：print("*")每次输出后换行；print("*", end="")修改结束符，默认end原为\n。可运行对照：

print("*")
print("*", end="")

【可读性改进】第11—13行可写 for row in range(rows):、for column in range(columns):、print("* ", end="")，给行内注释留两个空格，end两边不加额外空格；正常正整数输入时图形不变。原.md第8行 print(") 缺少闭合引号，应表达为 print("") 或直接 print()。

【输入边界】m=0或-1、n=2时原程序仅输出两个空行；非整数文本会抛ValueError。若需求要求有面积的矩形，应拒绝非正行列，属于新增输入约束。

前瞻优化：一次构造一行，再逐行打印，减少每行m次print调用为1次；仍需输出m×n个星号，不能说整体输出量变成O(n)。新知识是字符串重复 "* " * columns 与异常处理，行字符串占O(m)额外空间。完整替换例：

try:
    columns = int(input("请输入长度："))
    rows = int(input("请输入宽度："))
except ValueError:
    print("长和宽必须是整数")
else:
    if columns <= 0 or rows <= 0:
        print("长和宽必须大于0")
    else:
        line = "* " * columns
        for _ in range(rows):
            print(line)

合法正整数时保留原来的行末空格；非法输入改为给出提示。若目标是练习嵌套循环，应保留双层for对照。C的printf默认不换行，Python print默认换行。
