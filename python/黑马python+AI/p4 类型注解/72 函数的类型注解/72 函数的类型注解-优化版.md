函数参数和返回值写法：

```python
def calc(scores: list[int]) -> float:
    return sum(scores) / len(scores)

def calc_data(scores: list[int]) -> tuple[int, int, float]:
    max_v = max(scores)
    min_v = min(scores)
    avg_v = sum(scores) / len(scores)
    return max_v, min_v, avg_v
```

这里返回顺序是最高分、最低分、平均分；逗号形成一个三元素元组。

**补充（参考课程资料）：**参数默认值在注解后，如 `radius: float = 1.0`；不返回有意义结果时可写 `-> None`。注解不能代替输入校验。图中calc/calc_data约定非空成绩列表：空表下max/min会报错，sum/len会除零；这是该截图案例的输入域，不是下方圆计算当前出现的错误。

### 原始代码：[72 函数的类型注解.py](<72 函数的类型注解.py>)


```python
# 函数类型注解 
def circle_area_len(r: float) -> tuple[float, float]:
    return round(3.14 * r * r, 1), round(2 * 3.14 * r, 1)


al = circle_area_len(8.5)
print(al)
```

输入8.5，先算 `3.14 * 8.5 * 8.5` 并round到1位，再算 `2 * 3.14 * 8.5`；返回一个二元素元组。原文件与建议文件实际输出均为：
```text
(226.9, 53.4)
```

**纠正／C对照：**Python多个返回表达式组成一个tuple对象，无需按C方式通过多个输出参数才能返回这些值；`-> tuple[float, float]` 描述预期结果，不负责强制转换或限制只打印一位。`round`数值舍入和f-string格式化显示是两件事。
