![原图 image-1.png](<image-1.png>)

**图片文字版（来源：image-1.png）：**

HTTP为Hyper Text Transfer Protocol（超文本传输协议），约定客户端请求与服务端响应。课件特征：部分协议内容为文本、底层通过TCP、请求—响应、无状态；图示客户端发请求，服务端回响应。版本差异及“无状态”的边界在下方注明。

**纠正：**课件“文本＋TCP”主要对应HTTP/1.x；HTTP/2使用二进制帧，HTTP/3基于QUIC而非TCP（[HTTP/3标准](https://www.rfc-editor.org/rfc/rfc9114.html)）。TCP提供有序可靠字节流，不自动提供加密。无状态指协议不自动维持业务会话，不禁止服务端用cookie／session／数据库保存状态。

**图片文字版（来源：image-2.png）：**

小结：TCP/IP四层为应用、传输、网络、网络接口；HTTP约定客户端／服务端数据传输规则，课件以基于文本、请求响应、无状态概括。本课图示针对入门HTTP/1.1，不应覆盖所有HTTP版本。
