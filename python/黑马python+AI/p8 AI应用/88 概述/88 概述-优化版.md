**图片文字版（来源：image-2.png）：**

三种部署方案与课件优缺点：
|方案|课件优点|课件缺点|
|---|---|---|
|本地部署|数据安全、自主可控、长期成本低|初始成本高、长期维护、性能受限|
|官方开放API|前期成本低、无需部署维护、随时访问|隐私不能保障、长期成本高、可控性差|
|云服务平台|前期成本低、无需部署维护、选择度高|安全隐私不能保障、长期成本高|

图举阿里云百炼、百度千帆、火山引擎；API全称Application Programming Interface，软件间调用能力和数据的接口。以上评价是示意，绝对化结论在下方纠正。

**补充（参考课程资料）与纠正：**本地运行可减少把输入交给外部服务的需要，但不自动保证零外泄、零成本；应用日志、联网功能与权限仍影响结果。API免自己部署模型，不等于免应用运维或所有型号都同等能力。成本／隐私取决于具体配置和条款，不照搬绝对评价。
