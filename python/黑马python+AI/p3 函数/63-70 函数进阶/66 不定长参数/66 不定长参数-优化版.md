## 思考

### 为什么需要不定长

![原图 image.png](<image.png>)

**图片文字版（来源：image.png）：**

函数求一批数据的最小、最大、平均，输入项数不确定。图举4项、6项、9项：calc_data(389,39,29,105)、calc_data(15,18,3,27,89,35)、calc_data(100,45,78,15,183,96,27,89,35)。

固定写a/b/c/d不适合数量变化；也可传一个列表，本节采用*args演示另一种接口，不把列表参数说成不可行。


### 两类不定长参数

![原图 image-1.png](<image-1.png>)

**图片文字版（来源：image-1.png）：**

参数个数不确定（0个或多个）；分位置传递与关键字传递。

0个是语法允许，不意味着min/max/平均的算法能处理空数据；需要给出非空前置条件或清楚的异常。

## 关键字传递

### 双星号kwargs

![原图 image-3.png](<image-3.png>)

**图片文字版（来源：image-3.png）：**



```python
def calc_data(*args, **kwargs):
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)
    if kwargs.get("round"):
        avg_data = round(avg_data, kwargs.get("round"))
    return min_data, max_data, avg_data

print(calc_data(100,200,300,400,round=2,count=0))
print(calc_data(33,11,28,91,32,75,49))
```

关键字收成字典，kwargs也可叫options。

**纠正：**图中if kwargs.get("round")会跳过round=0；原.py已正确用is not None。键字符串"round"／"print"并不遮蔽内置名称。当前又sum/len一次可复用avg_data；缓存digits也减少重复get。教材有“打印后只返回平均值”与其三项代码不一致，本稿保留原.py三项返回契约；打印与返回互不替代。

**对应原始代码片段（保留注释状态）：**

```python
# -------------------- 函数 - 不定长参数(关键字参数 *kwargs --> 字典) --------------------

# 需求：根据传入的这些数据，计算这些数据的最小值，最大值，平均值
def calc_data(*args, **kwargs):
    """
    根据传入的这些数据，计算这些数据的最小值、最大值、平均值

    :param args: 不定长位置参数，需要计算的这些数据
    :param kwargs: 不定长关键字参数
        round: 保留的小数位个数
        print: 是否打印输出
    :return: 最小值、最大值、平均值
    """
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)

    if kwargs.get("round") is not None:
        avg_data = round(sum(args) / len(args), kwargs.get("round"))

    if kwargs.get("print"):# 本身就是bool类型,不用再判断
    
        print(f"计算出来的最大值:{max_data}, 最小值:{min_data}, 平均值:{avg_data}")

    return min_data, max_data, avg_data


# 调用函数
print(calc_data(2, 7, 9, 10, 45, round = 3, print = True))
print(calc_data(2, 7, 9, 10, 45, 73, 37, 93, 92, 111, 222,round = 2))
```

# # 需求：根据传入的这些数据，计算这些数据的最小值，最大值，平均值

# 需求：根据传入的这些数据，计算这些数据的最小值，最大值，平均值
def calc_data(*args, **kwargs):
    """
    根据传入的这些数据，计算这些数据的最小值、最大值、平均值

    :param args: 不定长位置参数，需要计算的这些数据
    :param kwargs: 不定长关键字参数
        round: 保留的小数位个数
        print: 是否打印输出
    :return: 最小值、最大值、平均值
    """
    # 原空args会在min报错；显式拒绝，输出错误信息更清楚。
    if not args:
        raise ValueError("至少传入一个数字")
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)

    # 原先再次sum/len且两次get；缓存选项并复用已算的avg_data。
    # 必须is not None，round=0也应有效；字符串键round/print不遮蔽内置函数。
    digits = kwargs.get("round")
    if digits is not None:
        avg_data = round(avg_data, digits)

    if kwargs.get("print"):# 本身就是bool类型,不用再判断
    
        print(f"计算出来的最大值:{max_data}, 最小值:{min_data}, 平均值:{avg_data}")

    return min_data, max_data, avg_data


# 调用函数

## 小结

### 小结与数据／选项

![原图 image-4.png](<image-4.png>)

**图片文字版（来源：image-4.png）：**

*args收不定量核心数据到tuple；**kwargs收不定量选项到dict。例：核心数据“珍珠奶茶”；选项甜度少糖、冰度去冰、加料布丁和珍珠、大小大杯。示例接口def calc_data(*args, **kwargs)。

新增语法只需理解*、**负责收集，名称不特殊。优化版仍保留当前round/print选项接口；空参数会以明确ValueError说明，没有暗中返回0。
