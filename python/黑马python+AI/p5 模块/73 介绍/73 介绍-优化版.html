模块介绍

图片文字版（来源：image.png）：

模块是组织Python代码的基本单元，常见形式是 .py 文件，可包含变量、函数、类及可执行语句。标准库举例：math数学、random随机、os操作系统、sys解释器交互、datetime日期时间、time时间、re正则、csv表格文本。图中随机点名示例：

import random

names = ["王林", "李慕婉",
         "许立国", "韩立",
         "涛哥", "莫厉海",
         "十三", "虎咆",
         "红蝶", "天运子"]
print(random.choice(names))

截图姓名用于示例，random.choice从非空序列选一个元素；不要把某次输出当作固定结果。

补充（参考课程资料）：拆出计算函数的目的是让多个入口复用；使用函数前先完成导入。Python模块不只一种物理形式（还可有内建／扩展模块），本课从.py文件入门。标准库通常无需额外pip安装；模块名不要取random.py、math.py以免遮蔽标准库。

纠正：导入通常会执行模块顶层语句，缓存后再次导入同一名字一般复用已加载模块；不能把import理解成C的文本include。包含打印、文件操作的顶层代码可能在导入时发生，演示文件和工具模块宜分开。
